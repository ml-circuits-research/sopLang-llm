# sopLang-llm project plan

The project fine-tunes a small code-capable language model to compile problems into SOP Lang circuits instead of generating final answers directly. The circuit is executed by a runtime that resolves dependencies, delegates deterministic work to JavaScript, calls explicitly declared tools or neural judgments, and returns a traceable result. Persistent typed containers let the model process sources that exceed its context window.
