# 12 — Some, all, and none at the Little River stall — case 2

A stall notice in Little River says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 4 boxes of each kind. Ben takes one pie and says this pie must contain nuts. Cara takes one soup and says this soup is vegetarian. Nia says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
