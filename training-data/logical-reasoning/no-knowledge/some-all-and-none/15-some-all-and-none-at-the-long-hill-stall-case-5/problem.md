# 15 — Some, all, and none at the Long Hill stall — case 5

A stall notice in Long Hill says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 4 boxes of each kind. Leo takes one pie and says this pie must contain nuts. Mira takes one soup and says this soup is vegetarian. Quinn says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
