# 19 — Some, all, and none at the East Wharf stall — case 9

A stall notice in East Wharf says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 5 boxes of each kind. Omar takes one pie and says this pie must contain nuts. Pia takes one soup and says this soup is vegetarian. Rafi says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
