# 16 — Some, all, and none at the Port Asher stall — case 6

A stall notice in Port Asher says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 5 boxes of each kind. Ade takes one pie and says this pie must contain nuts. Bela takes one soup and says this soup is vegetarian. Chris says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
