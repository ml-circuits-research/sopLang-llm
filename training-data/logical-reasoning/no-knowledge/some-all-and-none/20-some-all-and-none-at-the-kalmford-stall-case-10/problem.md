# 20 — Some, all, and none at the Kalmford stall — case 10

A stall notice in Kalmford says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 3 boxes of each kind. Sol takes one pie and says this pie must contain nuts. Una takes one soup and says this soup is vegetarian. Wes says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
