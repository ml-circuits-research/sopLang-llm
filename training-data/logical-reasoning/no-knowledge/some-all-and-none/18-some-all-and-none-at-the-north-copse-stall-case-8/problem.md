# 18 — Some, all, and none at the North Copse stall — case 8

A stall notice in North Copse says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 4 boxes of each kind. Jules takes one pie and says this pie must contain nuts. Kat takes one soup and says this soup is vegetarian. Ned says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
