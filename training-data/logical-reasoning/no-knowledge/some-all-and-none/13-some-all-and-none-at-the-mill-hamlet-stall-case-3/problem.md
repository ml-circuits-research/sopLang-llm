# 13 — Some, all, and none at the Mill Hamlet stall — case 3

A stall notice in Mill Hamlet says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 5 boxes of each kind. Farid takes one pie and says this pie must contain nuts. Gina takes one soup and says this soup is vegetarian. Pavel says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
