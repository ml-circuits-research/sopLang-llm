# 14 — Some, all, and none at the Wells Village stall — case 4

A stall notice in Wells Village says: “SOME boxed pies contain nuts. ALL boxed soups are vegetarian. NONE of the boxed juices contain milk.” There are 3 boxes of each kind. Harun takes one pie and says this pie must contain nuts. Iona takes one soup and says this soup is vegetarian. Ruth says a juice might still contain milk if the cook changed the recipe this morning.

Question. Which claim is forced, which is only possible, and which contradicts the notice?
