# 508 — Ranking the stories — North Copse dark lamp — case 8

A lamp in North Copse is dark. Listed: the switch is on; the neighbouring lamp on the same listed socket-strip is lit. Jules offers “the bulb is dead.” Kat offers “the town’s whole grid has failed.” Ned offers “a rare moth jammed a hidden second switch,” with no moth listed.

Question. Which story should start first, given the listed signs?
