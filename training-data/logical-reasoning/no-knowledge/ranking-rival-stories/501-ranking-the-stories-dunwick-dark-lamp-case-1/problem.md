# 501 — Ranking the stories — Dunwick dark lamp — case 1

A lamp in Dunwick is dark. Listed: the switch is on; the neighbouring lamp on the same listed socket-strip is lit. Sam offers “the bulb is dead.” Tess offers “the town’s whole grid has failed.” Owen offers “a rare moth jammed a hidden second switch,” with no moth listed.

Question. Which story should start first, given the listed signs?
