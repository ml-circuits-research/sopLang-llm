# Explanation 604 — A percent without a base — Wells Village poster — case 4

## Explanation

1. The poster in Wells Village announces a cut of 13%, but a percent is a sentence with a hole: it is always a percent of something, and no original price, date, or basket is listed.
2. Harun treats the poster as a finished quantity, which reads a number the page never printed.
3. Iona keeps the hole open and asks for the base, and the “down” also needs the date it is measured from.
4. Ruth fills the hole with a base of 130 to be helpful, but a helpful invention is still an invention: it writes a second poster instead of reading this one.

Reference solution as printed in the source (section 61, 5 steps):

1. A percent is of something.
2. That something is missing.
3. Helpful invention is still invention.
4. “Down” also needs “from when.”
5. Write “unknown base,” not a fake number.

## Result

**Answer.** Only a bare percent. Inventing 130 writes a second poster.
