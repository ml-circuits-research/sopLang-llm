# 254 — Counting the listed cases — Wells Village drawer — case 4

A drawer in Wells Village holds six labelled keys. Five open the shed; one is bent and does not. Harun says “some of these keys open the shed.” Iona says “all keys everywhere open sheds.” Ruth says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
