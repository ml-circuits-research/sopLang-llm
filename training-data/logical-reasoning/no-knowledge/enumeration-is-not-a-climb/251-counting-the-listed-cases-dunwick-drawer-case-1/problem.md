# 251 — Counting the listed cases — Dunwick drawer — case 1

A drawer in Dunwick holds six labelled keys. Five open the shed; one is bent and does not. Sam says “some of these keys open the shed.” Tess says “all keys everywhere open sheds.” Owen says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
