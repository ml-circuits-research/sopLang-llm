# 258 — Counting the listed cases — North Copse drawer — case 8

A drawer in North Copse holds six labelled keys. Five open the shed; one is bent and does not. Jules says “some of these keys open the shed.” Kat says “all keys everywhere open sheds.” Ned says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
