# 256 — Counting the listed cases — Port Asher drawer — case 6

A drawer in Port Asher holds six labelled keys. Five open the shed; one is bent and does not. Ade says “some of these keys open the shed.” Bela says “all keys everywhere open sheds.” Chris says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
