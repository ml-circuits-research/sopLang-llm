# 260 — Counting the listed cases — Kalmford drawer — case 10

A drawer in Kalmford holds six labelled keys. Five open the shed; one is bent and does not. Sol says “some of these keys open the shed.” Una says “all keys everywhere open sheds.” Wes says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
