# 253 — Counting the listed cases — Mill Hamlet drawer — case 3

A drawer in Mill Hamlet holds six labelled keys. Five open the shed; one is bent and does not. Farid says “some of these keys open the shed.” Gina says “all keys everywhere open sheds.” Pavel says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
