# 252 — Counting the listed cases — Little River drawer — case 2

A drawer in Little River holds six labelled keys. Five open the shed; one is bent and does not. Ben says “some of these keys open the shed.” Cara says “all keys everywhere open sheds.” Nia says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
