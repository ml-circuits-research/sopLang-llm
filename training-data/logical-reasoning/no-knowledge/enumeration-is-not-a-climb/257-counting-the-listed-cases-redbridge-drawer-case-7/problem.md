# 257 — Counting the listed cases — Redbridge drawer — case 7

A drawer in Redbridge holds six labelled keys. Five open the shed; one is bent and does not. Dora says “some of these keys open the shed.” Eli says “all keys everywhere open sheds.” Fran says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
