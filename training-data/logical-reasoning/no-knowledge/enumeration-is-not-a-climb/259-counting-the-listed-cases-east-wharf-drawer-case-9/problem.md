# 259 — Counting the listed cases — East Wharf drawer — case 9

A drawer in East Wharf holds six labelled keys. Five open the shed; one is bent and does not. Omar says “some of these keys open the shed.” Pia says “all keys everywhere open sheds.” Rafi says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
