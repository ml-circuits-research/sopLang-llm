# 255 — Counting the listed cases — Long Hill drawer — case 5

A drawer in Long Hill holds six labelled keys. Five open the shed; one is bent and does not. Leo says “some of these keys open the shed.” Mira says “all keys everywhere open sheds.” Quinn says the drawer is a complete list of the six, so “five of these six open the shed” is a count, not a climb.

Question. Which sentence is a count, and which is a climb?
