# 168 — The contrapositive in North Copse — case 8

Market card in North Copse: “If it rained in the last hour, the market pavement is wet.” Jules says the licensed twin is: if the pavement is not wet, it did not rain in the last hour. Kat says the licensed twin is: if the pavement is wet, it rained in the last hour. Ned cannot hear a difference.

Question. Which twin did the card already buy?
