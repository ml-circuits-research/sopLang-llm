# 828 — The first number pulls — North Copse hall — case 8

A host in North Copse jokes that the hall holds 80. Later, two clerks independently count 18 chairs and 17. People asked for a quick guess after the joke still hover near forty. Jules says the joke cannot pull because it was a joke. Kat names anchoring: the first number occupies a slot. Ned says 80 is as live as 18.

Question. Can a first number pull even as a joke?
