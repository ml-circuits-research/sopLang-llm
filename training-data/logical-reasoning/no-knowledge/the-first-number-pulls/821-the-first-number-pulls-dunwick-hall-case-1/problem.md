# 821 — The first number pulls — Dunwick hall — case 1

A host in Dunwick jokes that the hall holds 80. Later, two clerks independently count 18 chairs and 17. People asked for a quick guess after the joke still hover near forty. Sam says the joke cannot pull because it was a joke. Tess names anchoring: the first number occupies a slot. Owen says 80 is as live as 18.

Question. Can a first number pull even as a joke?
