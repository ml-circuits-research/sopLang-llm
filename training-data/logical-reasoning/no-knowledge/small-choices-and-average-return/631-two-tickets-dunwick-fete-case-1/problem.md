# 631 — Two tickets — Dunwick fete — case 1

Fete in Dunwick. Game One: pay 2; half the tickets win 4; half win nothing. Game Two: pay 20; one ticket in 100 wins 1600; the rest win nothing. Sam feels Game Two is wiser because the prize is huge. Tess compares average return from the printed fractions. Owen says feeling lucky is a number.

Question. Which game has the better average return on the stall’s fractions?
