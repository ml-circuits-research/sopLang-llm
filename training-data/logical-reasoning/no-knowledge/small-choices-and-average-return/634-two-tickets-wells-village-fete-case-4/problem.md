# 634 — Two tickets — Wells Village fete — case 4

Fete in Wells Village. Game One: pay 2; half the tickets win 4; half win nothing. Game Two: pay 20; one ticket in 100 wins 1600; the rest win nothing. Harun feels Game Two is wiser because the prize is huge. Iona compares average return from the printed fractions. Ruth says feeling lucky is a number.

Question. Which game has the better average return on the stall’s fractions?
