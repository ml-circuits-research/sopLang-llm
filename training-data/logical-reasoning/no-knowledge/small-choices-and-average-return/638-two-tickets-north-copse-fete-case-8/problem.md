# 638 — Two tickets — North Copse fete — case 8

Fete in North Copse. Game One: pay 2; half the tickets win 4; half win nothing. Game Two: pay 20; one ticket in 100 wins 1600; the rest win nothing. Jules feels Game Two is wiser because the prize is huge. Kat compares average return from the printed fractions. Ned says feeling lucky is a number.

Question. Which game has the better average return on the stall’s fractions?
