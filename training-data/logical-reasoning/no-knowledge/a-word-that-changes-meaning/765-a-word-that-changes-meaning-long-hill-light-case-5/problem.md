# 765 — A word that changes meaning — Long Hill light — case 5

Notice in Long Hill: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Leo carries a heavy lamp because “light is required.” Mira says the word shifted: first “not-heavy,” then “illumination.” Quinn says a repeated word always keeps one meaning.
