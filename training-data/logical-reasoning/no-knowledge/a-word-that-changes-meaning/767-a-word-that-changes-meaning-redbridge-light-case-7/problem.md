# 767 — A word that changes meaning — Redbridge light — case 7

Notice in Redbridge: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Dora carries a heavy lamp because “light is required.” Eli says the word shifted: first “not-heavy,” then “illumination.” Fran says a repeated word always keeps one meaning.

Question. What happened to the word?
