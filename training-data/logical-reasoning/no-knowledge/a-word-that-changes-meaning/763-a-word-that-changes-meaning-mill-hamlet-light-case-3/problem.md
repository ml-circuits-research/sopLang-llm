# 763 — A word that changes meaning — Mill Hamlet light — case 3

Notice in Mill Hamlet: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Farid carries a heavy lamp because “light is required.” Gina says the word shifted: first “not-heavy,” then “illumination.” Pavel says a repeated word always keeps one meaning.

Question. What happened to the word?
