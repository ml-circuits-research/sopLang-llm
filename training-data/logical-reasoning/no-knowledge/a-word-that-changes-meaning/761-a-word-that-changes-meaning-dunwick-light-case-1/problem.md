# 761 — A word that changes meaning — Dunwick light — case 1

Notice in Dunwick: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Sam carries a heavy lamp because “light is required.” Tess says the word shifted: first “not-heavy,” then “illumination.” Owen says a repeated word always keeps one meaning.

Question. What happened to the word?
