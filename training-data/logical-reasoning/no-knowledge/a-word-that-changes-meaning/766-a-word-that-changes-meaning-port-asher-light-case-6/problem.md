# 766 — A word that changes meaning — Port Asher light — case 6

Notice in Port Asher: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Ade carries a heavy lamp because “light is required.” Bela says the word shifted: first “not-heavy,” then “illumination.” Chris says a repeated word always keeps one meaning.
