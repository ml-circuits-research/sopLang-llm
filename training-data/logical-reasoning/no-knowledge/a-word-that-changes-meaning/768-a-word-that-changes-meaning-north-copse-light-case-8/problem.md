# 768 — A word that changes meaning — North Copse light — case 8

Notice in North Copse: “Use only light tools on this floor.” A later line on the same notice uses “light” to mean illumination (“keep a light on”). Jules carries a heavy lamp because “light is required.” Kat says the word shifted: first “not-heavy,” then “illumination.” Ned says a repeated word always keeps one meaning.

Question. What happened to the word?
