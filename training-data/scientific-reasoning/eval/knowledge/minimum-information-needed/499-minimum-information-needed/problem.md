# 499 — Minimum information needed

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. After the observation “the unusual value exists, but its cause has not yet been identified,” both hypotheses remain possible: H1: the unusual value is a random error; H2: the instrument is misadjusted. We can make one additional observation.

Question. What is the minimum information that would separate the hypotheses? Explain why a shared observation does not help, while a discriminating one does.
