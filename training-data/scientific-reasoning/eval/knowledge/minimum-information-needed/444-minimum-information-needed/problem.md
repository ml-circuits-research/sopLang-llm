# 444 — Minimum information needed

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. after the observation “source lit”, both hypotheses remain possible: H1: the shadow is missing because of the object transparent and H2: the shadow is missing because of the screen. We can make one additional observation.

Question. What is the minimum information that would separate the hypotheses? Explain why a shared observation does not help, while a discriminating one does.
