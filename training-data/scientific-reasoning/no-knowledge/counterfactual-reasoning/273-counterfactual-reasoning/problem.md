# 273 — Counterfactual reasoning

Problem world. For insect L in this problem, the life cycle has four stages in order: egg, larva, pupa, adult. Only the adult lays eggs, and a larva cannot become an adult without passing through the pupal stage. A temperature in the suitable range may change the rate of development, but it does not change the order of the stages.

Case data. The causal network is: viable egg → larva appears; larva appears → can reach the pupa stage; reaches the pupa stage → the adult can emerge; adult emerges → new eggs can be laid. In the normal situation, we start with “egg viable”. Now imagine that “larva appears” is completely blocked: it can neither be produced nor produce effects.

Question. Which effects that occurred before can no longer be obtained through this path? Explain the difference between the normal world and the counterfactual world.
