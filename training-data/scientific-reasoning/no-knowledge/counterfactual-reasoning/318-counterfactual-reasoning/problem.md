# 318 — Counterfactual reasoning

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. The causal network is: source lit → light toward object; light toward object → the object receives light; opaque object → a part from light is blocked; light blocked → shade on screen. In the normal situation, we start with “source lit”. Now imagine that “light toward object” is completely blocked: it can neither be produced nor produce effects.

Question. Which effects that occurred before can no longer be obtained through this path? Explain the difference between the normal world and the counterfactual world.
