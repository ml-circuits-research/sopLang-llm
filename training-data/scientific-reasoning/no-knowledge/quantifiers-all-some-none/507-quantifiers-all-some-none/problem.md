# 507 — Quantifiers: all, some, none

Given knowledge. Seeds can be dispersed by wind, water, or animals. In the model, a seed reaches a new place only if it leaves the parent plant and remains capable of germinating after transport. Light seeds or seeds with wings can be carried more easily by wind. Some fruits have hooks that attach to fur.

Problem data. The observations for the five cases are: the seed with wing A: is light in weight, can float; the fruit with hooks B: can cling; the fruit floating C: is light in weight, can cling; the acorn D: can cling, can float; the seed fluffy E: is light in weight, can cling, can float.

Question. Decide whether each statement is true or false in the table: all cases with the property “is light in weight” also have the property “can cling”. / some cases with the property “is light in weight” also have the property “can cling”. / no case with the property “can cling” does not have the property “can float”. / some cases with the property “can float” do not have the property “is light in weight”. For every false statement, give a counterexample; for a true existential statement, give a witness.
