# 517 — Quantifiers: all, some, none

Given knowledge. Soil is a mixture that may contain mineral particles, humus, water, and air. In the model, a good layer for roots must retain some water while also leaving air spaces; too much water without air, or drainage that is too fast, can create problems. Sand generally has larger particles than clay. Humus comes from transformed organic remains.

Problem data. The observations for the five cases are: the sample A: retains air-filled pores; the sample B: drains quickly, contains humus; the sample C: drains quickly, retains air-filled pores; the sample D: contains humus, retains air-filled pores; the sample E: drains quickly, contains humus, retains air-filled pores.

Question. Decide whether each statement is true or false in the table: all cases with the property “drains quickly” also have the property “contains humus”. / some cases with the property “drains quickly” also have the property “contains humus”. / no case with the property “contains humus” does not have the property “retains air-filled pores”. / some cases with the property “retains air-filled pores” do not have the property “drains quickly”. For every false statement, give a counterexample; for a true existential statement, give a witness.
