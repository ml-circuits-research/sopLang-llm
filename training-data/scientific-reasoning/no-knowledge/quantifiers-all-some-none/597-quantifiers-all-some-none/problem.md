# 597 — Quantifiers: all, some, none

Given knowledge. In the model, the Moon does not produce its own visible light; it reflects sunlight. Half of the Moon is illuminated by the Sun, and the phase seen from Earth depends on the relative positions of the Sun, Earth, and Moon. Moon phases are not caused by Earth’s shadow; Earth’s shadow matters during a lunar eclipse. The Moon travels in orbit around Earth.

Problem data. The observations for the five cases are: the position A: shows the illuminated part, is opposite the Sun, is between Earth and Sun; the position B: shows the illuminated part, is between Earth and Sun; the position C: is opposite the Sun; the position D: shows the illuminated part; the observer E: is opposite the Sun, is between Earth and Sun.

Question. Decide whether each statement is true or false in the table: all cases with the property “shows the illuminated part” also have the property “is opposite the Sun”. / some cases with the property “shows the illuminated part” also have the property “is opposite the Sun”. / no case with the property “is opposite the Sun” does not have the property “is between Earth and Sun”. / some cases with the property “is between Earth and Sun” do not have the property “shows the illuminated part”. For every false statement, give a counterexample; for a true existential statement, give a witness.
