# 537 — Quantifiers: all, some, none

Given knowledge. During exercise, muscles need more oxygen and energy, and pulse and breathing may increase. after exercise stops, the values tend to return gradually toward the resting level. In the model, recovery is tracked by measurements taken at the same time intervals. Sweating can contribute to water loss. A single measurement does not describe the whole recovery process.

Problem data. The observations for the five cases are: the student A: has complete measurements; the student B: has complete measurements, made the same effort; the student C: made the same effort; the student D: made the same effort, values decrease gradually; the student E: has complete measurements, values decrease gradually.

Question. Decide whether each statement is true or false in the table: all cases with the property “has complete measurements” also have the property “made the same effort”. / some cases with the property “has complete measurements” also have the property “made the same effort”. / no case with the property “made the same effort” does not have the property “values decrease gradually”. / some cases with the property “values decrease gradually” do not have the property “has complete measurements”. For every false statement, give a counterexample; for a true existential statement, give a witness.
