# 532 — Quantifiers: all, some, none

Given knowledge. Incisors cut, canines can tear, and molars crush and grind. Enamel protects the outside of the tooth. In the model, preparing a piece of food well requires cutting or tearing and then grinding before swallowing. Teeth have different shapes for different mechanical roles. Chewing increases the surface area of pieces of food.

Problem data. The observations for the five cases are: the incisor A: can cut, removes deposits; the canine B: can crush; the molar C: can cut, can crush; the toothbrush D: can crush, removes deposits; the piece E: can cut, can crush, removes deposits.

Question. Decide whether each statement is true or false in the table: all cases with the property “can cut” also have the property “can crush”. / some cases with the property “can cut” also have the property “can crush”. / no case with the property “can crush” does not have the property “removes deposits”. / some cases with the property “removes deposits” do not have the property “can cut”. For every false statement, give a counterexample; for a true existential statement, give a witness.
