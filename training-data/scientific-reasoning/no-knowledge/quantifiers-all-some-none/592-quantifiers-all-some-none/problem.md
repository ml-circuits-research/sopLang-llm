# 592 — Quantifiers: all, some, none

Given knowledge. Energy can be transferred and transformed. In the model, a battery stores chemical energy, a circuit transfers it electrically, a bulb produces light and heat, and a motor produces motion and heat. A device does not create energy from nothing. Useful energy depends on the purpose of the device.

Problem data. The observations for the five cases are: the battery A: produces motion; the bulb B: stores energy, produces light; the motor C: stores energy, produces motion; the wire D: produces light, produces motion; the resistor E: stores energy, produces light, produces motion.

Question. Decide whether each statement is true or false in the table: all cases with the property “stores energy” also have the property “produces light”. / some cases with the property “stores energy” also have the property “produces light”. / no case with the property “produces light” does not have the property “produces motion”. / some cases with the property “produces motion” do not have the property “stores energy”. For every false statement, give a counterexample; for a true existential statement, give a witness.
