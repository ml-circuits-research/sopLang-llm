# 527 — Quantifiers: all, some, none

Given knowledge. Bones support the body, joints allow movement between certain bones, and muscles pull on bones when they contract. In the arm model, bending the forearm requires a movable joint, a muscle that contracts, and a bone through which the force is transmitted. Muscles pull; they do not push a bone from a distance. Different joints allow different types of movement.

Problem data. The observations for the five cases are: the bone A: is rigid, can transmit force; the joint B: is rigid; the muscle C: can transmit force, can actively shorten; the tendon D: is rigid, can transmit force, can actively shorten; the bone E: can actively shorten.

Question. Decide whether each statement is true or false in the table: all cases with the property “is rigid” also have the property “can transmit force”. / some cases with the property “is rigid” also have the property “can transmit force”. / no case with the property “can transmit force” does not have the property “can actively shorten”. / some cases with the property “can actively shorten” do not have the property “is rigid”. For every false statement, give a counterexample; for a true existential statement, give a witness.
