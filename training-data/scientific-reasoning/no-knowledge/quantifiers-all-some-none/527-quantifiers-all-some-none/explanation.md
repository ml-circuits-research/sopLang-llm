# Explanation 527 — Quantifiers: all, some, none

## Explanation

1. Every property becomes a category of cases, so the four statements reduce to questions about membership lists: all is rigid cases in the can transmit force category, some case in both, no case in both can transmit force and can actively shorten, and some can actively shorten case outside is rigid.
2. Statement 1 is false: the joint B carries is rigid without can transmit force.
3. Statement 2 is true: the bone A carries both properties.
4. Statement 3 is false: the muscle C is in both categories, and statement 4 is true: the muscle C is a witness.

Reference solution as printed in the source (form 22, 4 steps):

1. For “all” we look for counterexamples; for “some” we look for at least one witness; for “none” we check if the intersection is empty.
2. Statement 1 is false: counterexample the joint B.
3. Statement 2 is true: witness the bone A.
4. Statements 3 and 4 are, respectively: false — the muscle C is in both categories; true — witness the muscle C.
