# 587 — Quantifiers: all, some, none

Given knowledge. In the circuit model, the metals used here are conductors, while plastic and rubber are insulators. Current appears only if there is a continuous conducting path between the source terminals; insulation is used to prevent contact with conducting parts. A conductor allows current to pass in the model. An insulator breaks the electrical path.

Problem data. The observations for the five cases are: the wire A: is conductor; the clamp B: is conductor, is insulated on the outside; the seed coat C: is insulated on the outside; the switch D: is insulated on the outside, can close the path; the bulb E: is conductor, can close the path.

Question. Decide whether each statement is true or false in the table: all cases with the property “is conductor” also have the property “is insulated on the outside”. / some cases with the property “is conductor” also have the property “is insulated on the outside”. / no case with the property “is insulated on the outside” does not have the property “can close the path”. / some cases with the property “can close the path” do not have the property “is conductor”. For every false statement, give a counterexample; for a true existential statement, give a witness.
