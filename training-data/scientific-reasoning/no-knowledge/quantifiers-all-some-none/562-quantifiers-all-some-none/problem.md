# 562 — Quantifiers: all, some, none

Given knowledge. For equal volumes, the material with smaller mass has lower density. In the model, an object floats in water if its average density is lower than the density of water; a hollow shape can contain air and reduce average density. A compact piece of metal can be denser than water. A metal ship can float because its total volume contains a great deal of air.

Problem data. The observations for the five cases are: the object A: has an air cavity; the object B: has an air cavity, has a large volume; the object C: has a large volume; the object D: has a large volume, has low mass for its volume; the object E: has an air cavity, has low mass for its volume.

Question. Decide whether each statement is true or false in the table: all cases with the property “has an air cavity” also have the property “has a large volume”. / some cases with the property “has an air cavity” also have the property “has a large volume”. / no case with the property “has a large volume” does not have the property “has low mass for its volume”. / some cases with the property “has low mass for its volume” do not have the property “has an air cavity”. For every false statement, give a counterexample; for a true existential statement, give a witness.
