# 577 — Quantifiers: all, some, none

Given knowledge. A mirror does not produce light; it changes the direction of light that reaches its surface. In the grid-ray model, the outgoing angle is symmetric with the incoming angle relative to the normal to the mirror. Light travels in straight lines in the uniform medium of the model. A matte surface scatters light in many directions.

Problem data. The observations for the five cases are: mirror A: reflects toward right, is diagonally oriented; mirror B: reflects toward right; the screen C: is diagonally oriented, is on the route; the source D: reflects toward right, is diagonally oriented, is on the route; the obstacle E: is on the route.

Question. Decide whether each statement is true or false in the table: all cases with the property “reflects toward right” also have the property “is diagonally oriented”. / some cases with the property “reflects toward right” also have the property “is diagonally oriented”. / no case with the property “is diagonally oriented” does not have the property “is on the route”. / some cases with the property “is on the route” do not have the property “reflects toward right”. For every false statement, give a counterexample; for a true existential statement, give a witness.
