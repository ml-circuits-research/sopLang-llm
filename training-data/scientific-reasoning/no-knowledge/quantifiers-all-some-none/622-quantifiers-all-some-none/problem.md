# 622 — Quantifiers: all, some, none

Given knowledge. In the kitchen model, heating transfers energy, dissolving forms a homogeneous mixture only for certain substances and quantities, and clean utensils reduce contamination. Experimental recipes can be compared only when quantities and times are measured in the same way. A dissolved substance has not disappeared; it is distributed through the solvent. Stirring can speed dissolving without changing the maximum amount allowed by the model.

Problem data. The observations for the five cases are: the container A: is clean, keeps heat, allows the measurement of the temperature; the container B: is clean, allows the measurement of the temperature; the spoon C: keeps heat; the lid D: is clean; the thermometer E: keeps heat, allows the measurement of the temperature.

Question. Decide whether each statement is true or false in the table: all cases with the property “is clean” also have the property “keeps heat”. / some cases with the property “is clean” also have the property “keeps heat”. / no case with the property “keeps heat” does not have the property “allows the measurement of the temperature”. / some cases with the property “allows the measurement of the temperature” do not have the property “is clean”. For every false statement, give a counterexample; for a true existential statement, give a witness.
