# 612 — Quantifiers: all, some, none

Given knowledge. In the home model, insulation slows heat transfer, natural light can reduce the use of electric lights, and electrical devices transform energy and also produce heat. The goal is comfort while using resources as efficiently as possible. Windows can provide light but can also be areas of heat transfer. A thick curtain can reduce some heat loss.

Problem data. The observations for the five cases are: room A: has good insulation; room B: has good insulation, uses natural light; room C: uses natural light; room D: uses natural light, switches off unnecessary loads; room E: has good insulation, switches off unnecessary loads.

Question. Decide whether each statement is true or false in the table: all cases with the property “has good insulation” also have the property “uses natural light”. / some cases with the property “has good insulation” also have the property “uses natural light”. / no case with the property “uses natural light” does not have the property “switches off unnecessary loads”. / some cases with the property “switches off unnecessary loads” do not have the property “has good insulation”. For every false statement, give a counterexample; for a true existential statement, give a witness.
