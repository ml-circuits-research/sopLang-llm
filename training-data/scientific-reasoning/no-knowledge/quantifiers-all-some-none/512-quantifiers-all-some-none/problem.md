# 512 — Quantifiers: all, some, none

Given knowledge. Fungi and bacteria can decompose organic remains. In the model, active decomposition needs decomposers, enough water, and a suitable temperature; the matter in the remains is transformed and some substances return to the soil. Dead leaves do not disappear instantly; decomposition has stages. Strong drying can slow the activity of many decomposers.

Problem data. The observations for the five cases are: the leaf A: is moist; the twig B: is moist, is broken into smaller pieces; the shell C: is broken into smaller pieces; dry grass D: is broken into smaller pieces, is reached by decomposers; the remainder of fruit E: is moist, is reached by decomposers.

Question. Decide whether each statement is true or false in the table: all cases with the property “is moist” also have the property “is broken into smaller pieces”. / some cases with the property “is moist” also have the property “is broken into smaller pieces”. / no case with the property “is broken into smaller pieces” does not have the property “is reached by decomposers”. / some cases with the property “is reached by decomposers” do not have the property “is moist”. For every false statement, give a counterexample; for a true existential statement, give a witness.
