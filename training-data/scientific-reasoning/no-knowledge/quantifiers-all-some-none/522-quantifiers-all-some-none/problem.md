# 522 — Quantifiers: all, some, none

Given knowledge. Animals can respond to seasons through migration, hibernation, storing food, or changing their coat. In the model, a strategy succeeds if the animal secures energy, protection, and access to resources under the season’s conditions. Migration means seasonal movement between regions. Hibernation greatly reduces activity during certain periods.

Problem data. The observations for the five cases are: the animal A: migrates, stores food, has a protected shelter; the animal B: migrates, has a protected shelter; the animal C: stores food; the animal D: migrates; the animal E: stores food, has a protected shelter.

Question. Decide whether each statement is true or false in the table: all cases with the property “migrates” also have the property “stores food”. / some cases with the property “migrates” also have the property “stores food”. / no case with the property “stores food” does not have the property “has a protected shelter”. / some cases with the property “has a protected shelter” do not have the property “migrates”. For every false statement, give a counterexample; for a true existential statement, give a witness.
