# 582 — Quantifiers: all, some, none

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. The observations for the five cases are: the wall A: is hard, absorbs a lot in the model; the curtain B: is porous; the panel C: is hard, is porous; the floor D: is porous, absorbs a lot in the model; the ceiling E: is hard, is porous, absorbs a lot in the model.

Question. Decide whether each statement is true or false in the table: all cases with the property “is hard” also have the property “is porous”. / some cases with the property “is hard” also have the property “is porous”. / no case with the property “is porous” does not have the property “absorbs a lot in the model”. / some cases with the property “absorbs a lot in the model” do not have the property “is hard”. For every false statement, give a counterexample; for a true existential statement, give a witness.
