# 552 — Quantifiers: all, some, none

Given knowledge. Two gears that touch directly rotate in opposite directions. In the model, if a small gear drives a larger gear, the larger gear makes fewer rotations in the same time; an odd or even number of contacts can change the final direction. The teeth prevent slipping in the ideal model. An intermediate gear can change direction without being the useful output.

Problem data. The observations for the five cases are: the gear A: has 10 teeth, is in direct contact with A; the gear B: has 10 teeth; the gear C: is in direct contact with A, is the output gear; the gear D: has 10 teeth, is in direct contact with A, is the output gear; the gear E: is the output gear.

Question. Decide whether each statement is true or false in the table: all cases with the property “has 10 teeth” also have the property “is in direct contact with A”. / some cases with the property “has 10 teeth” also have the property “is in direct contact with A”. / no case with the property “is in direct contact with A” does not have the property “is the output gear”. / some cases with the property “is the output gear” do not have the property “has 10 teeth”. For every false statement, give a counterexample; for a true existential statement, give a witness.
