# 547 — Quantifiers: all, some, none

Given knowledge. A lever has a fulcrum, a load, and a place where effort is applied. In the numerical model, for the same load, moving the effort farther from the fulcrum can reduce the force required. The fulcrum is the point around which the lever rotates. The effort arm is the distance between the applied effort and the fulcrum.

Problem data. The observations for the five cases are: lever A: has a long effort arm, has a fixed support, changes the direction of the force; lever B: has a long effort arm, changes the direction of the force; lever C: has a fixed support; lever D: has a long effort arm; lever E: has a fixed support, changes the direction of the force.

Question. Decide whether each statement is true or false in the table: all cases with the property “has a long effort arm” also have the property “has a fixed support”. / some cases with the property “has a long effort arm” also have the property “has a fixed support”. / no case with the property “has a fixed support” does not have the property “changes the direction of the force”. / some cases with the property “changes the direction of the force” do not have the property “has a long effort arm”. For every false statement, give a counterexample; for a true existential statement, give a witness.
