# 53 — If-then logical chain

Problem world. Our model mixture contains iron filings, pebbles, sand, and salt dissolved in water. A magnet attracts the iron filings; a sieve separates larger particles from smaller ones; filtration can retain sand while water passes through; evaporating the water can leave the salt behind. A method must be chosen according to the property that differs between the components.

Case data. The local rules form a single chain: In the model, if “we use the magnet” has been completed, then “we use the sieve” can begin. In the model, if “we use the sieve” has been completed, then “we filter the liquid” can begin. In the model, if “we filter the liquid” has been completed, then “we evaporate the water” can begin. We know that “we use the magnet” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
