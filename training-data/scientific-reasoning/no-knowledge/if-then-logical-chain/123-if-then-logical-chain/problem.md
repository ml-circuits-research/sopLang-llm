# 123 — If-then logical chain

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. The local rules form a single chain: In the model, if “we define what we measure” has been completed, then “we choose the instrument and unit” can begin. In the model, if “we choose the instrument and unit” has been completed, then “we measure several times” can begin. In the model, if “we measure several times” has been completed, then “we compare values” can begin. We know that “we define what we measure” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
