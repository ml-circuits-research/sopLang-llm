# 103 — If-then logical chain

Problem world. In the model, Earth is approximated as a sphere rotating around its axis. The side facing the Sun is illuminated, while the opposite side is in night. As Earth rotates, a place can move from the illuminated region to the dark region and back again. These problems do not require astronomical distances or real durations; we use only the stated geometric model.

Case data. The local rules form a single chain: In the model, if “the location is in zone illuminated” has been completed, then “Earth rotates” can begin. In the model, if “Earth rotates” has been completed, then “the location reaches toward the edge of the zone illuminated” can begin. In the model, if “the location reaches toward the edge of the zone illuminated” has been completed, then “the location enters zone of night” can begin. We know that “the location is in zone illuminated” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
