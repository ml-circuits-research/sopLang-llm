# 88 — If-then logical chain

Problem world. In a simple-circuit model, a battery, wires, and a bulb must form a closed path for the bulb to light. A break anywhere along the path opens the circuit. Some materials conduct and can bridge a gap; others are insulators. We do not use details about voltage or current; every conclusion follows only from the idea of a continuous path.

Case data. The local rules form a single chain: In the model, if “we connect the battery” has been completed, then “we close the path through the wires” can begin. In the model, if “we close the path through the wires” has been completed, then “the path passes through the bulb” can begin. In the model, if “the path passes through the bulb” has been completed, then “the bulb lights up” can begin. We know that “we connect the battery” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
