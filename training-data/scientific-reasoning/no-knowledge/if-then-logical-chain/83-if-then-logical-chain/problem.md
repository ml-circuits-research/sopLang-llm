# 83 — If-then logical chain

Problem world. In the model, a magnet can attract certain magnetic materials without direct contact. Two magnet ends can attract or repel depending on orientation. We do not assume that all metals are magnetic; the result of the test is stated explicitly for every object. A thin nonmagnetic barrier does not necessarily stop the magnet’s effect in our model.

Case data. The local rules form a single chain: In the model, if “we bring closer the magnet” has been completed, then “the object enters the action zone” can begin. In the model, if “the object enters the action zone” has been completed, then “attraction occurs” can begin. In the model, if “attraction occurs” has been completed, then “the object moves toward the magnet” can begin. We know that “we bring closer the magnet” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
