# 113 — If-then logical chain

Problem world. In the model, a pollutant introduced into a stream can be transported downstream. Reducing pollution at its source stops part of the problem before it spreads. Cleanup downstream can help locally, but it does not necessarily replace stopping the source. A good decision compares desired effects, costs, and side effects using the given data.

Case data. The local rules form a single chain: In the model, if “the pollutant enters the stream” has been completed, then “the water carries it downstream” can begin. In the model, if “the water carries it downstream” has been completed, then “downstream organisms have been exposed” can begin. In the model, if “downstream organisms have been exposed” has been completed, then “effects may appear farther from the source” can begin. We know that “the pollutant enters the stream” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
