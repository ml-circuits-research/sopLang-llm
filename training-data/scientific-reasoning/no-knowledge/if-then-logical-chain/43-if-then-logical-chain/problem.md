# 43 — If-then logical chain

Problem world. In the model, microbes can transfer from a surface to the hands and then from the hands to the mouth if the hands are not cleaned. Correct washing with soap and water greatly reduces the number of microbes on the hands, without meaning that every microbe in the world disappears. To reduce risk, we can break the transmission chain at several points.

Case data. The local rules form a single chain: In the model, if “microbes reach the surface” has been completed, then “has transferred onto the hands” can begin. In the model, if “has transferred onto the hands” has been completed, then “hands touch the mouth” can begin. In the model, if “hands touch the mouth” has been completed, then “microbes can enters body” can begin. We know that “microbes reach the surface” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
