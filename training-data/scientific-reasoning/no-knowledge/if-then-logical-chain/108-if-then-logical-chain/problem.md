# 108 — If-then logical chain

Problem world. In our model, rock fragments can be broken off by weathering, transported by water or wind, and then deposited when the transporting agent loses energy. Repeated deposits can form layers. Traces or remains of organisms can become trapped in sediments and, under certain conditions, become fossils. A fossil does not form instantly; the problem uses only the logical order of the stages, not their real duration.

Case data. The local rules form a single chain: In the model, if “the rock breaks into fragments” has been completed, then “the fragments have been transported” can begin. In the model, if “the fragments have been transported” has been completed, then “the fragments have been deposited” can begin. In the model, if “the fragments have been deposited” has been completed, then “forms layers of sediment” can begin. We know that “the rock breaks into fragments” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
