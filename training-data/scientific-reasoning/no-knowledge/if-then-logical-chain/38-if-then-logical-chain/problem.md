# 38 — If-then logical chain

Problem world. In our model, a sensory receptor detects a stimulus, sends a nerve signal, the control center interprets the information, and muscles can produce a response. If the signal does not reach the control center, a response based on that signal cannot be chosen correctly. A fast response is not automatically a correct response; the information must first be detected and transmitted.

Case data. The local rules form a single chain: In the model, if “the receptor detects the stimulus” has been completed, then “the signal starts” can begin. In the model, if “the signal starts” has been completed, then “the signal is interpreted” can begin. In the model, if “the signal is interpreted” has been completed, then “the muscle performs the response” can begin. We know that “the receptor detects the stimulus” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
