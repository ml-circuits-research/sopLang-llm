# 33 — If-then logical chain

Problem world. In the simplified model, inhaled air brings oxygen into the lungs; oxygen passes into the blood, and the blood carries it to the cells. Cells produce carbon dioxide, which is carried by the blood back to the lungs and then exhaled. If one transport link is blocked, stages after that link receive less of the transported substance.

Case data. The local rules form a single chain: In the model, if “air enters the lungs” has been completed, then “oxygen passes into the blood” can begin. In the model, if “oxygen passes into the blood” has been completed, then “the blood transports oxygen” can begin. In the model, if “the blood transports oxygen” has been completed, then “oxygen reaches the cells” can begin. We know that “air enters the lungs” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
