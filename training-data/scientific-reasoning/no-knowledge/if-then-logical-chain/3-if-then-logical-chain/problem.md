# 3 — If-then logical chain

Problem world. For the imaginary bean species F in this problem, a seed begins germination only if it has water, air, and a suitable temperature. Light is not required for the first step of germination, but it becomes important after the green shoot appears. In our model, if any required condition is missing, germination stops at that point.

Case data. The local rules form a single chain: In the model, if “the seed absorbs water” has been completed, then “the seed coat softens” can begin. In the model, if “the seed coat softens” has been completed, then “the young root emerges” can begin. In the model, if “the young root emerges” has been completed, then “the shoot appears” can begin. We know that “the seed absorbs water” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
