# 48 — If-then logical chain

Problem world. Choosing a material depends on the properties required by the object, such as waterproofness, flexibility, transparency, or thermal insulation. No material is “the best” in every situation; it is suitable if it meets the requirements of its use at the same time. In this problem, the properties are stated explicitly and do not need to be guessed from everyday experience.

Case data. The local rules form a single chain: In the model, if “we establish the requirements” has been completed, then “we test the properties” can begin. In the model, if “we test the properties” has been completed, then “we eliminate the materials unsuitable” can begin. In the model, if “we eliminate the materials unsuitable” has been completed, then “we choose the material which meets all the requirements” can begin. We know that “we establish the requirements” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
