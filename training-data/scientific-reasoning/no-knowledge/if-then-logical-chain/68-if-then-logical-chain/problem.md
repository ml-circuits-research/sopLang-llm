# 68 — If-then logical chain

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. The local rules form a single chain: In the model, if “the source emits light” has been completed, then “light reaches the object” can begin. In the model, if “light reaches the object” has been completed, then “the opaque object blocks part of the light” can begin. In the model, if “the opaque object blocks part of the light” has been completed, then “a shadowed area appears on the screen” can begin. We know that “the source emits light” has been completed.

Question. What conclusions can we deduce successively? Show why each conclusion becomes a premise for the next rule.
