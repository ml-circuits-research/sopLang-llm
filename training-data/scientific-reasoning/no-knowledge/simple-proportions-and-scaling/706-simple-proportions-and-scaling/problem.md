# 706 — Simple proportions and scaling

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. In the contest’s simplified numerical model, each absorbent panel produces exactly 3 echo-reduction units in the same interval, and the effects add linearly. With 2 active units, we obtain 6 echo-reduction units.

Question. How many echo-reduction units do we obtain with 5 active units? How many active units are needed for 18 echo-reduction units? Show the scaling factor, not only the product.
