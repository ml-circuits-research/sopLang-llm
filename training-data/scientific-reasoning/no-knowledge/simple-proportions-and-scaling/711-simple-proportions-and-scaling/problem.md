# 711 — Simple proportions and scaling

Given knowledge. In the circuit model, the metals used here are conductors, while plastic and rubber are insulators. Current appears only if there is a continuous conducting path between the source terminals; insulation is used to prevent contact with conducting parts. A conductor allows current to pass in the model. An insulator breaks the electrical path.

Problem data. In the contest’s simplified numerical model, each conductive segment produces exactly 4 useful contacts in the same interval, and the effects add linearly. With 2 active units, we obtain 8 useful contacts.

Question. How many useful contacts do we obtain with 5 active units? How many active units are needed for 24 useful contacts? Show the scaling factor, not only the product.
