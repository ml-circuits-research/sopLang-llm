# 789 — The question with the greatest information gain

Given knowledge. During exercise, muscles need more oxygen and energy, and pulse and breathing may increase. after exercise stops, the values tend to return gradually toward the resting level. In the model, recovery is tracked by measurements taken at the same time intervals. Sweating can contribute to water loss. A single measurement does not describe the whole recovery process.

Problem data. An unknown case is one of: the student A: made the same effort, has complete measurements, values decrease gradually; the student B: made the same effort, values decrease gradually; the student C: values decrease gradually; the student D: none.

Question. You may ask one YES/NO question about one of the three properties. Choose the question that minimizes the maximum number of candidates remaining in the worst case.
