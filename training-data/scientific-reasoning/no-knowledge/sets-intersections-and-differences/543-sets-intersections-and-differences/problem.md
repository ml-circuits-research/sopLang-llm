# 543 — Sets, intersections, and differences

Given knowledge. Microorganisms can multiply on food when they find suitable conditions. In the model, cooling slows multiplication, drying reduces available water, and a clean container reduces initial contamination; none of these measures means that a food becomes sterile. Heat and moisture can speed some biological processes. “Cold” means slowing in the model, not absolute stopping.

Problem data. We use the properties as set labels. The sample A: is in a clean container; the sample B: is cooled, is dry; the sample C: is cooled, is in a clean container; the sample D: is dry, is in a clean container; the sample E: is cooled, is dry, is in a clean container.

Question. Construct A=“is cooled”, B=“is dry”, C=“is in a clean container”. Calculate A∩B∩C, B\C and A∪B. Explain for each operation what you keep and what you eliminate.
