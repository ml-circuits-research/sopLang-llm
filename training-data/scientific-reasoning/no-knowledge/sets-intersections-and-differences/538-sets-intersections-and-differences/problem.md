# 538 — Sets, intersections, and differences

Given knowledge. During exercise, muscles need more oxygen and energy, and pulse and breathing may increase. after exercise stops, the values tend to return gradually toward the resting level. In the model, recovery is tracked by measurements taken at the same time intervals. Sweating can contribute to water loss. A single measurement does not describe the whole recovery process.

Problem data. We use the properties as set labels. The student A: has complete measurements; the student B: has complete measurements, made the same effort; the student C: made the same effort; the student D: made the same effort, values decrease gradually; the student E: has complete measurements, values decrease gradually.

Question. Construct A=“has complete measurements”, B=“made the same effort”, C=“values decrease gradually”. Calculate B∩C, A\B and A∪C. Explain for each operation what you keep and what you eliminate.
