# 548 — Sets, intersections, and differences

Given knowledge. A lever has a fulcrum, a load, and a place where effort is applied. In the numerical model, for the same load, moving the effort farther from the fulcrum can reduce the force required. The fulcrum is the point around which the lever rotates. The effort arm is the distance between the applied effort and the fulcrum.

Problem data. We use the properties as set labels. Lever A: has a long effort arm, has a fixed support, changes the direction of the force; lever B: has a long effort arm, changes the direction of the force; lever C: has a fixed support; lever D: has a long effort arm; lever E: has a fixed support, changes the direction of the force.

Question. Construct A=“has a long effort arm”, B=“has a fixed support”, C=“changes the direction of the force”. Calculate A∩B, A∩C and C\A. Explain for each operation what you keep and what you eliminate.
