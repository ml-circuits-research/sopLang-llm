# 583 — Sets, intersections, and differences

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. We use the properties as set labels. The wall A: is hard, absorbs a lot in the model; the curtain B: is porous; the panel C: is hard, is porous; the floor D: is porous, absorbs a lot in the model; the ceiling E: is hard, is porous, absorbs a lot in the model.

Question. Construct A=“is hard”, B=“is porous”, C=“absorbs a lot in the model”. Calculate B∩C, A\B and A∪C. Explain for each operation what you keep and what you eliminate.
