# 162 — Predicting a change

Problem world. In our model, a sensory receptor detects a stimulus, sends a nerve signal, the control center interprets the information, and muscles can produce a response. If the signal does not reach the control center, a response based on that signal cannot be chosen correctly. A fast response is not automatically a correct response; the information must first be detected and transmitted.

Case data. Before the change, the system is stable. Now we activate or increase “stimulus visible”. The causal rules are: stimulus visible → the receptor detects it. The receptor detects it → nerve signal. Nerve signal → information interpreted. Information interpreted → command for muscle.

Question. Predict the effects that may appear downstream. Separate the direct effect from the indirect effects.
