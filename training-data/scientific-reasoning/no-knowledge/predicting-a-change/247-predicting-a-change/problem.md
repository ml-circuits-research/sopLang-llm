# 247 — Predicting a change

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. Before the change, the system is stable. Now we activate or increase “the same unit”. The causal rules are: the same unit → direct comparison. Measurements repeated → we can observe unusual values. Instrument checked → lower risk of systematic error. Conditions equal → the difference can be attributed to the tested factor.

Question. Predict the effects that may appear downstream. Separate the direct effect from the indirect effects.
