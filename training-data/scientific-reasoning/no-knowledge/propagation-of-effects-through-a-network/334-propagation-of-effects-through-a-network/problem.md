# 334 — Propagation of effects through a network

Problem world. In the model, a magnet can attract certain magnetic materials without direct contact. Two magnet ends can attract or repel depending on orientation. We do not assume that all metals are magnetic; the result of the test is stated explicitly for every object. A thin nonmagnetic barrier does not necessarily stop the magnet’s effect in our model.

Case data. The network of dependencies has the arrows: short distance → effect magnetic detectable; orientation of attraction → force toward magnet; force toward magnet → the object moves; object magnetic → answer test. We change “short distance”.

Question. Mark every node the effect can reach, directly or indirectly. Do not include nodes for which no arrow path exists.
