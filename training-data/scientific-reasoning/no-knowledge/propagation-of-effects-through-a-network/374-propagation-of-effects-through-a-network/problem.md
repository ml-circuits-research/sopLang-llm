# 374 — Propagation of effects through a network

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. The network of dependencies has the arrows: the same unit → direct comparison; measurements repeated → we can observe unusual values; instrument checked → lower risk of systematic error; conditions equal → the difference can be attributed to the tested factor. We change “the same unit”.

Question. Mark every node the effect can reach, directly or indirectly. Do not include nodes for which no arrow path exists.
