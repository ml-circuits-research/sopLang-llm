# 886 — Structural analogy between systems

Given knowledge. Fungi and bacteria can decompose organic remains. In the model, active decomposition needs decomposers, enough water, and a suitable temperature; the matter in the remains is transformed and some substances return to the soil. Dead leaves do not disappear instantly; decomposition has stages. Strong drying can slow the activity of many decomposers.

Problem data. System 1 has the following functional chain: “the remainder falls” prepares “the remains become moist”, which allows “decomposers colonize”, which in turn produces or prepares “the remains break into smaller pieces”. System 2, completely artificial, has this structure: the Source sends an object to the Preparation Station; the station sends it through the Channel; at the end, the Collector receives it. The analogy must be based on roles and links, not on appearance.

Question. Build a correspondence between the four roles in System 1 and Source / Preparation Station / Channel / Collector in System 2. What structural property does the analogy preserve?
