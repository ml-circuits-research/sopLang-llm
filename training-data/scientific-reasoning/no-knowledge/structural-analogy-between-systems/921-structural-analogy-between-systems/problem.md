# 921 — Structural analogy between systems

Given knowledge. A lever has a fulcrum, a load, and a place where effort is applied. In the numerical model, for the same load, moving the effort farther from the fulcrum can reduce the force required. The fulcrum is the point around which the lever rotates. The effort arm is the distance between the applied effort and the fulcrum.

Problem data. System 1 has the following functional chain: “the support is fixed” prepares “the load is positioned”, which allows “the point of effort is chosen”, which in turn produces or prepares “the force is applied”. System 2, completely artificial, has this structure: the Source sends an object to the Preparation Station; the station sends it through the Channel; at the end, the Collector receives it. The analogy must be based on roles and links, not on appearance.

Question. Build a correspondence between the four roles in System 1 and Source / Preparation Station / Channel / Collector in System 2. What structural property does the analogy preserve?
