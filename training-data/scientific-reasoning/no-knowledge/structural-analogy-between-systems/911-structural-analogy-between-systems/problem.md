# 911 — Structural analogy between systems

Given knowledge. During exercise, muscles need more oxygen and energy, and pulse and breathing may increase. after exercise stops, the values tend to return gradually toward the resting level. In the model, recovery is tracked by measurements taken at the same time intervals. Sweating can contribute to water loss. A single measurement does not describe the whole recovery process.

Problem data. System 1 has the following functional chain: “resting state is measured” prepares “the effort is performed”, which allows “the effort stops”, which in turn produces or prepares “the measurement is repeated”. System 2, completely artificial, has this structure: the Source sends an object to the Preparation Station; the station sends it through the Channel; at the end, the Collector receives it. The analogy must be based on roles and links, not on appearance.

Question. Build a correspondence between the four roles in System 1 and Source / Preparation Station / Channel / Collector in System 2. What structural property does the analogy preserve?
