# 976 — Structural analogy between systems

Given knowledge. In the greenhouse model, plants need light and water, temperature must remain within a stated range, and fruit formation in the species used requires pollination. Windows can cool and ventilate, watering adds water, and insect access can increase pollination. Too much water can reduce the air in the soil. Ventilation can lower temperature and humidity.

Problem data. System 1 has the following functional chain: “the sensor measures” prepares “the intervention is decided”, which allows “water is distributed”, which in turn produces or prepares “temperature is regulated”. System 2, completely artificial, has this structure: the Source sends an object to the Preparation Station; the station sends it through the Channel; at the end, the Collector receives it. The analogy must be based on roles and links, not on appearance.

Question. Build a correspondence between the four roles in System 1 and Source / Preparation Station / Channel / Collector in System 2. What structural property does the analogy preserve?
