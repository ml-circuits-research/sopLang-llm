# 881 — Structural analogy between systems

Given knowledge. Seeds can be dispersed by wind, water, or animals. In the model, a seed reaches a new place only if it leaves the parent plant and remains capable of germinating after transport. Light seeds or seeds with wings can be carried more easily by wind. Some fruits have hooks that attach to fur.

Problem data. System 1 has the following functional chain: “the fruit ripens” prepares “the seed detaches”, which allows “the agent transports it”, which in turn produces or prepares “the seed is deposited”. System 2, completely artificial, has this structure: the Source sends an object to the Preparation Station; the station sends it through the Channel; at the end, the Collector receives it. The analogy must be based on roles and links, not on appearance.

Question. Build a correspondence between the four roles in System 1 and Source / Preparation Station / Channel / Collector in System 2. What structural property does the analogy preserve?
