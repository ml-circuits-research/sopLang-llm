# 486 — Competing hypotheses

Problem world. In the model, a pollutant introduced into a stream can be transported downstream. Reducing pollution at its source stops part of the problem before it spreads. Cleanup downstream can help locally, but it does not necessarily replace stopping the source. A good decision compares desired effects, costs, and side effects using the given data.

Case data. Hypothesis 1: H1: the source of pollution is still active → predictions [increases after discharge, level large near source, stopping the source reduces rapid the input new]. Hypothesis 2: H2: the pollutant is in sediments old → predictions [increasing does not follow discharges new, level decreases slowly, the source is stopped]. In the experiment, we observe “increases after discharge”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
