# 441 — Competing hypotheses

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. Hypothesis 1: H1: the shadow is missing because of the object transparent → predictions [screen aligned, light passes through object, source lit]. Hypothesis 2: H2: the shadow is missing because of the screen → predictions [the screen is not behind the object, opaque object, source lit]. In the experiment, we observe “screen aligned”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
