# 436 — Competing hypotheses

Problem world. In the model, heat transfers from a warmer body toward a cooler one until the difference becomes smaller. An insulating material slows heat transfer; it does not “make cold” or create energy. For a fair comparison, containers must begin at the same temperature and be observed for the same amount of time.

Case data. Hypothesis 1: H1: insulation is weak → predictions [lid closed, rapid cooling, layer thin]. Hypothesis 2: H2: the lid is problem → predictions [lid open, rapid cooling, the insulating layer is good]. In the experiment, we observe “lid closed”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
