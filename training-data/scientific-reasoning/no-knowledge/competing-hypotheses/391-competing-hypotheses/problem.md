# 391 — Competing hypotheses

Problem world. In this problem, a habitat provides resources such as water, food, shelter, and a tolerable temperature. An adaptation is a characteristic that helps an organism in a particular environment; the same characteristic is not equally useful in every environment. For animal Z in the model, good survival requires water, food, and shelter at the same time.

Case data. Hypothesis 1: H1: problem main is heat → predictions [low activity at noon, activity returns evening, water there is]. Hypothesis 2: H2: problem main is the lack of the water → predictions [low activity all day, the animals leaves, spring dry]. In the experiment, we observe “low activity at noon”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
