# 496 — Competing hypotheses

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. Hypothesis 1: H1: the value unusual is a random error → predictions [the instrument passes the check, a alone measurement differs, the repeated measurements groups]. Hypothesis 2: H2: the instrument is misadjusted → predictions [another instrument gives a different level, repetition keeps deviation, all the measurements are shifted]. In the experiment, we observe “the instrument passes the check”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
