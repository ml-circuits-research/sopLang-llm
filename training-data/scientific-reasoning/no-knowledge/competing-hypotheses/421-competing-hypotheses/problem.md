# 421 — Competing hypotheses

Problem world. Choosing a material depends on the properties required by the object, such as waterproofness, flexibility, transparency, or thermal insulation. No material is “the best” in every situation; it is suitable if it meets the requirements of its use at the same time. In this problem, the properties are stated explicitly and do not need to be guessed from everyday experience.

Case data. Hypothesis 1: H1: the loss of heat is through material → predictions [the container remains closed, temperature decreases quickly, a layer insulator helps]. Hypothesis 2: H2: the loss is through opening → predictions [temperature decreases quickly, the wall type matters little, closing helps]. In the experiment, we observe “the container remains closed”.

Question. Which hypothesis is better supported, and which is eliminated by this observation in the model? State the conclusion without saying more than the data allow.
