# 832 — Counterexample and falsification of a rule

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. The table of observations is: the wall A: is hard, absorbs a lot in the model; the curtain B: is porous; the panel C: is hard, is porous; the floor D: is porous, absorbs a lot in the model; the ceiling E: is hard, is porous, absorbs a lot in the model. A peer states: “any case with the property “is porous” also has the property “is hard”.”

Question. Is the universal statement true in the given data? If not, provide a counterexample and explain exactly which part of the statement it refutes.
