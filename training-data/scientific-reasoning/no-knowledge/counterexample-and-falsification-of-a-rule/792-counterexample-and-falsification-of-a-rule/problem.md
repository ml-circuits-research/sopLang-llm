# 792 — Counterexample and falsification of a rule

Given knowledge. Microorganisms can multiply on food when they find suitable conditions. In the model, cooling slows multiplication, drying reduces available water, and a clean container reduces initial contamination; none of these measures means that a food becomes sterile. Heat and moisture can speed some biological processes. “Cold” means slowing in the model, not absolute stopping.

Problem data. The table of observations is: the sample A: is in a clean container; the sample B: is cooled, is dry; the sample C: is cooled, is in a clean container; the sample D: is dry, is in a clean container; the sample E: is cooled, is dry, is in a clean container. A peer states: “any case with the property “is in a clean container” also has the property “is cooled”.”

Question. Is the universal statement true in the given data? If not, provide a counterexample and explain exactly which part of the statement it refutes.
