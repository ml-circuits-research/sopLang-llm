# 193 — Inferring a hidden state

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. In this model, each sign listed below can be produced only by the causes listed: source off → no well-defined shadow appears, there is no light beam. Object transparent → light passes, shadow is very weak. Screen positioned incorrectly → the object blocks the light, the shadow does not fall on the screen. We observe the sign “the object blocks the light”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
