# 228 — Inferring a hidden state

Problem world. In the model, Earth is approximated as a sphere rotating around its axis. The side facing the Sun is illuminated, while the opposite side is in night. As Earth rotates, a place can move from the illuminated region to the dark region and back again. These problems do not require astronomical distances or real durations; we use only the stated geometric model.

Case data. In this model, each sign listed below can be produced only by the causes listed: the model does not rotate → the same point remains illuminated, no alternation appears in the test. The source of light is off → the model cannot represent day, no part is illuminated. Observer moved → the comparison no longer tracks the same place, the order of the observations changes. We observe the sign “the same point remains illuminated”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
