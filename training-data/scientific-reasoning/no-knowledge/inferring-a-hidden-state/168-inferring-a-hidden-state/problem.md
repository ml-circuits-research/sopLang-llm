# 168 — Inferring a hidden state

Problem world. In the model, microbes can transfer from a surface to the hands and then from the hands to the mouth if the hands are not cleaned. Correct washing with soap and water greatly reduces the number of microbes on the hands, without meaning that every microbe in the world disappears. To reduce risk, we can break the transmission chain at several points.

Case data. In this model, each sign listed below can be produced only by the causes listed: unwashed hands → microbes remain on hands, surface was reached. Surface very contaminated → more people have contact, the hands contaminates rapid. Food unprotected → microbes reach direct on food, the hands can be clean. We observe the sign “microbes remain on hands”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
