# 173 — Inferring a hidden state

Problem world. Choosing a material depends on the properties required by the object, such as waterproofness, flexibility, transparency, or thermal insulation. No material is “the best” in every situation; it is suitable if it meets the requirements of its use at the same time. In this problem, the properties are stated explicitly and do not need to be guessed from everyday experience.

Case data. In this model, each sign listed below can be produced only by the causes listed: material unsuitable for water → water passes, the test of waterproofing fails. Material too rigid → does not bend, the remainder of the properties can be good. Material opaque → light does not pass, can be waterproof. We observe the sign “does not bend”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
