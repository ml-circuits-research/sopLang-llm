# 163 — Inferring a hidden state

Problem world. In our model, a sensory receptor detects a stimulus, sends a nerve signal, the control center interprets the information, and muscles can produce a response. If the signal does not reach the control center, a response based on that signal cannot be chosen correctly. A fast response is not automatically a correct response; the information must first be detected and transmitted.

Case data. In this model, each sign listed below can be produced only by the causes listed: stimulus too weak → does not start the signal, the receiver does not detect. Path of signal blocked → the center does not receive the signal, the receiver detects. Muscle blocked → no motion appears, the signal is interpreted. We observe the sign “the center does not receive the signal”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
