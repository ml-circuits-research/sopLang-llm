# 248 — Inferring a hidden state

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. In this model, each sign listed below can be produced only by the causes listed: units different → is necessary conversion given, the numbers does not compare direct. Instrument misadjusted → repetition alone does not correct cause, all values are shifted in the same direction. Random error → a single value differs greatly, the repeated measurements are close between they. We observe the sign “a single value differs greatly”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
