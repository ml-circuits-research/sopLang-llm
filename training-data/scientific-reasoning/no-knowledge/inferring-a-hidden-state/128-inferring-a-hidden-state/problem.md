# 128 — Inferring a hidden state

Problem world. For the imaginary bean species F in this problem, a seed begins germination only if it has water, air, and a suitable temperature. Light is not required for the first step of germination, but it becomes important after the green shoot appears. In our model, if any required condition is missing, germination stops at that point.

Case data. In this model, each sign listed below can be produced only by the causes listed: lack of water → mass does not increase, the seed remains dry. Lack of air → the rootlet does not appear, the seed is humid. Temperature too low → the processes are very slow, the seed is humid. We observe the sign “the rootlet does not appear”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
