# 213 — Inferring a hidden state

Problem world. In a simple-circuit model, a battery, wires, and a bulb must form a closed path for the bulb to light. A break anywhere along the path opens the circuit. Some materials conduct and can bridge a gap; others are insulators. We do not use details about voltage or current; every conclusion follows only from the idea of a continuous path.

Case data. In this model, each sign listed below can be produced only by the causes listed: switch open → bulb off, all the wires can be good. broken wire → bulb off, switch closed. Bulb disconnected → bulb off, the path bypasses the bulb. We observe the sign “switch closed”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
