# 158 — Inferring a hidden state

Problem world. In the simplified model, inhaled air brings oxygen into the lungs; oxygen passes into the blood, and the blood carries it to the cells. Cells produce carbon dioxide, which is carried by the blood back to the lungs and then exhaled. If one transport link is blocked, stages after that link receive less of the transported substance.

Case data. In this model, each sign listed below can be produced only by the causes listed: air insufficient in lungs → little oxygen in lungs, little oxygen in blood. Poor lung-to-blood transfer → air reaches the lungs, little oxygen in blood. Circulation weak → reaches the cells with difficulty, oxygen enters the blood. We observe the sign “air reaches the lungs”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
