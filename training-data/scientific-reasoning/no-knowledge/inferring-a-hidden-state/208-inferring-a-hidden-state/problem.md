# 208 — Inferring a hidden state

Problem world. In the model, a magnet can attract certain magnetic materials without direct contact. Two magnet ends can attract or repel depending on orientation. We do not assume that all metals are magnetic; the result of the test is stated explicitly for every object. A thin nonmagnetic barrier does not necessarily stop the magnet’s effect in our model.

Case data. In this model, each sign listed below can be produced only by the causes listed: object nonmagnetic → the magnet works on another object, does not moves at proximity of the magnet. Distance too large → does not move until the magnet approaches, object magnetic. Orientation of rejection → two magnets moves away, changing the orientation changes the effect. We observe the sign “does not move until the magnet approaches”.

Question. Which hidden state remains possible? Note: we may reason from effect to cause only because the problem declares the list of causes complete within this model.
