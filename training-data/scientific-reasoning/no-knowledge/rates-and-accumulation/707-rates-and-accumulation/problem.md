# 707 — Rates and accumulation

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. The quantity tracked is “sound energy” (unit: load units). We start with 4 load units; in each equal interval, the net change is +2 load units; we track 4 intervals.

Question. Write the sequence of values after each interval, then calculate the value after two more intervals if the rate remains constant.
