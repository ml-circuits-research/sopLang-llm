# 119 — Choice under multiple conditions

Problem world. In the teaching model, foods can provide energy and substances needed to build and operate the body. A balanced meal is not decided by a single food but by the combination and amount. For this problem, each option has explicitly stated properties; no real food values need to be memorized. We track three requirements at the same time: enough energy, a source of protein, and a source of fiber.

Case data. Option A: provides enough energy: YES; contains source of protein: YES; contains fiber: YES; the amount of sugar is below the given limit: NO. Option B: provides enough energy: YES; contains source of protein: NO; contains fiber: YES; the amount of sugar is below the given limit: YES. Option C: provides enough energy: NO; contains source of protein: YES; contains fiber: YES; the amount of sugar is below the given limit: YES. Option D: provides enough energy: YES; contains source of protein: YES; contains fiber: YES; the amount of sugar is below the given limit: YES.

Question. Choose the option that simultaneously meets all conditions: the amount of sugar is below the given limit, contains fiber, contains source of protein, provides enough energy. If even one mandatory condition is NO, the option must be eliminated. Which one remains, and why can the “count the most YES values” method give a wrong answer?
