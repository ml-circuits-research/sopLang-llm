# 713 — Intervals, bounds, and possibility

Given knowledge. In the circuit model, the metals used here are conductors, while plastic and rubber are insulators. Current appears only if there is a continuous conducting path between the source terminals; insulation is used to prevent contact with conducting parts. A conductor allows current to pass in the model. An insulator breaks the electrical path.

Problem data. The accepted zone for “number of correct contacts” is the closed interval [8,12] contacts; each result is known only as interval: A=[8,9]; B=[11,13]; C=[13,15]; D=[6,7].

Question. For each sample, say whether it is certainly accepted, certainly rejected, or still uncertain. Then identify which sample would benefit most from a more precise measurement.
