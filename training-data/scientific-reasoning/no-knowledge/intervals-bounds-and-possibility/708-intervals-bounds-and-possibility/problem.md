# 708 — Intervals, bounds, and possibility

Given knowledge. An echo occurs when sound is reflected and returns after a delay. Hard, smooth surfaces can reflect more sound, while soft or porous materials can absorb a larger share. Sound propagates through vibrations in a medium. A greater distance to the wall increases the echo’s return time.

Problem data. The accepted zone for “echo level” is the closed interval [7,11] units; each result is known only as interval: A=[5,6]; B=[7,8]; C=[10,12]; D=[12,14].

Question. For each sample, say whether it is certainly accepted, certainly rejected, or still uncertain. Then identify which sample would benefit most from a more precise measurement.
