# 678 — Intervals, bounds, and possibility

Given knowledge. Two gears that touch directly rotate in opposite directions. In the model, if a small gear drives a larger gear, the larger gear makes fewer rotations in the same time; an odd or even number of contacts can change the final direction. The teeth prevent slipping in the ideal model. An intermediate gear can change direction without being the useful output.

Problem data. The accepted zone for “output rotations” is the closed interval [7,11] rotations/min; each result is known only as interval: A=[10,12]; B=[12,14]; C=[5,6]; D=[7,8].

Question. For each sample, say whether it is certainly accepted, certainly rejected, or still uncertain. Then identify which sample would benefit most from a more precise measurement.
