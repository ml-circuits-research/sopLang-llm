# 317 — Is the evidence sufficient?

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. Two hypotheses remain possible. H1: the shadow is missing because of the object transparent predicts [screen aligned, light passes through object, source lit]. H2: the shadow is missing because of the screen predicts [the screen is not behind the object, opaque object, source lit]. Until now we know only “source lit”, while the problem explicitly states that this information is compatible with both hypotheses.

Question. Is this information sufficient to choose a hypothesis? If not, what evidence would genuinely discriminate between them?
