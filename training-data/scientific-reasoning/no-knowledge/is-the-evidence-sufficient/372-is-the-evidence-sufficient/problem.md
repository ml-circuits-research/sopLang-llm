# 372 — Is the evidence sufficient?

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. Two hypotheses remain possible. H1: the value unusual is a random error predicts [the instrument passes the check, a alone measurement differs, the repeated measurements groups]. H2: the instrument is misadjusted predicts [another instrument gives a different level, repetition keeps deviation, all the measurements are shifted]. Until now we know only “the general problem that both hypotheses try to explain”, while the problem explicitly states that this information is compatible with both hypotheses.

Question. Is this information sufficient to choose a hypothesis? If not, what evidence would genuinely discriminate between them?
