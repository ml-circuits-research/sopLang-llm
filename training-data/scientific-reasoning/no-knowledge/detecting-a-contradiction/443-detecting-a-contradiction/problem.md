# 443 — Detecting a contradiction

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. A student writes the conclusion: “Case A meets all mandatory conditions, including nothing blocks the source before the object.” The problem data includes: In the data, for case A, “nothing blocks the source before the object” is NO.

Question. Find the exact contradiction. Which statements cannot be true at the same time, and what minimum correction must be made?
