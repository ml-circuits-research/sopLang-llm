# 246 — Diagnosis from clues

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. The possible causes and their signs are: units different: is necessary conversion given, the numbers does not compare direct. Instrument misadjusted: repetition alone does not correct cause, all values are shifted in the same direction. Random error: a single value differs greatly, the repeated measurements are close between they. We observe: a single value differs greatly, the repeated measurements are close between they.

Question. Which cause is best supported by the observations? Also check why the other explanations do not fit all the data.
