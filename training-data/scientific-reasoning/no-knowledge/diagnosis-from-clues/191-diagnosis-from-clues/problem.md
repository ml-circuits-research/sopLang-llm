# 191 — Diagnosis from clues

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. The possible causes and their signs are: source off: no well-defined shadow appears, there is no light beam. Object transparent: light passes, shadow is very weak. Screen positioned incorrectly: the object blocks the light, the shadow does not fall on the screen. We observe: the object blocks the light, the shadow does not fall on the screen.

Question. Which cause is best supported by the observations? Also check why the other explanations do not fit all the data.
