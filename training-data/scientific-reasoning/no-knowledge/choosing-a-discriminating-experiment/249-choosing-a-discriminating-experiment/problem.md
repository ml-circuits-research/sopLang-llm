# 249 — Choosing a discriminating experiment

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. We have two explanations: H1: the value unusual is a random error predicts [the instrument passes the check, a alone measurement differs, the repeated measurements groups], while H2: the instrument is misadjusted predicts [another instrument gives a different level, repetition keeps deviation, all the measurements are shifted]. The shared observation “the observed problem exists, but its cause has not yet been located” does not distinguish them.

Question. Choose a test that would produce a different observation for the two hypotheses. What should we check, and what result would support each hypothesis?
