# 144 — Choosing a discriminating experiment

Problem world. In this problem, a habitat provides resources such as water, food, shelter, and a tolerable temperature. An adaptation is a characteristic that helps an organism in a particular environment; the same characteristic is not equally useful in every environment. For animal Z in the model, good survival requires water, food, and shelter at the same time.

Case data. We have two explanations: H1: problem main is heat predicts [low activity at noon, activity returns evening, water there is], while H2: problem main is the lack of the water predicts [low activity all day, the animals leaves, spring dry]. The shared observation “the observed problem exists, but its cause has not yet been located” does not distinguish them.

Question. Choose a test that would produce a different observation for the two hypotheses. What should we check, and what result would support each hypothesis?
