# 239 — Choosing a discriminating experiment

Problem world. In the model, a pollutant introduced into a stream can be transported downstream. Reducing pollution at its source stops part of the problem before it spreads. Cleanup downstream can help locally, but it does not necessarily replace stopping the source. A good decision compares desired effects, costs, and side effects using the given data.

Case data. We have two explanations: H1: the source of pollution is still active predicts [increases after discharge, level large near source, stopping the source reduces rapid the input new], while H2: the pollutant is in sediments old predicts [increasing does not follow discharges new, level decreases slowly, the source is stopped]. The shared observation “the observed problem exists, but its cause has not yet been located” does not distinguish them.

Question. Choose a test that would produce a different observation for the two hypotheses. What should we check, and what result would support each hypothesis?
