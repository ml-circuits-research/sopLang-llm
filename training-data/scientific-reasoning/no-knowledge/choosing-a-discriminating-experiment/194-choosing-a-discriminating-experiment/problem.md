# 194 — Choosing a discriminating experiment

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. We have two explanations: H1: the shadow is missing because of the object transparent predicts [screen aligned, light passes through object, source lit], while H2: the shadow is missing because of the screen predicts [the screen is not behind the object, opaque object, source lit]. The shared observation “source lit” does not distinguish them.

Question. Choose a test that would produce a different observation for the two hypotheses. What should we check, and what result would support each hypothesis?
