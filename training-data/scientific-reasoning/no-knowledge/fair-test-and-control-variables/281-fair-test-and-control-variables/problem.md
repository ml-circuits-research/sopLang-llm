# 281 — Fair test and control variables

Problem world. In the simplified model, inhaled air brings oxygen into the lungs; oxygen passes into the blood, and the blood carries it to the cells. Cells produce carbon dioxide, which is carried by the blood back to the lungs and then exhaled. If one transport link is blocked, stages after that link receive less of the transported substance.

Case data. We want to test the effect of the factor “number of breaths per minute in the model exercise”. The group A receives level 10, the group B level 30. For a fair test, the following must be kept constant: the same effort, the same person-model, the same interval.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
