# 336 — Fair test and control variables

Problem world. In a simple-circuit model, a battery, wires, and a bulb must form a closed path for the bulb to light. A break anywhere along the path opens the circuit. Some materials conduct and can bridge a gap; others are insulators. We do not use details about voltage or current; every conclusion follows only from the idea of a continuous path.

Case data. We want to test the effect of the factor “number of breaks in the path”. The group A receives level 0, the group B level 2. For a fair test, the following must be kept constant: the same battery, the same bulb, the same remaining wires.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
