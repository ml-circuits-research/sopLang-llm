# 351 — Fair test and control variables

Problem world. In the model, Earth is approximated as a sphere rotating around its axis. The side facing the Sun is illuminated, while the opposite side is in night. As Earth rotates, a place can move from the illuminated region to the dark region and back again. These problems do not require astronomical distances or real durations; we use only the stated geometric model.

Case data. We want to test the effect of the factor “model rotation angle”. The group A receives level 0, the group B level 180. For a fair test, the following must be kept constant: the same source, the same point marked, the same source position.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
