# 276 — Fair test and control variables

Problem world. In the simplified model used here, food is broken into smaller pieces in the mouth, reaches the stomach, and then the small intestine, where much of the nutrients pass into the blood. In the large intestine, some water is recovered from the remaining material. The order of the organs matters: a substance cannot reach a later part of the intestine before passing through earlier parts of the route.

Case data. We want to test the effect of the factor “degree to which the food is broken up”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same quantity of food, the same time, the same model digestive.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
