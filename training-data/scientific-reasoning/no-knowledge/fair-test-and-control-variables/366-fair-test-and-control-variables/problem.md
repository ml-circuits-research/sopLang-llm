# 366 — Fair test and control variables

Problem world. In the teaching model, foods can provide energy and substances needed to build and operate the body. A balanced meal is not decided by a single food but by the combination and amount. For this problem, each option has explicitly stated properties; no real food values need to be memorized. We track three requirements at the same time: enough energy, a source of protein, and a source of fiber.

Case data. We want to test the effect of the factor “the number of components balanced from mass”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same quantity total, the same interval, the same criteria of evaluation.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
