# 341 — Fair test and control variables

Problem world. In the model, air occupies space, water flows through open spaces, and soils differ in how quickly they allow water to pass. Soil with different particles and spaces may retain more or less water; this property is measured in the test rather than guessed. To compare two soils, we pour the same amount of water and wait the same amount of time.

Case data. We want to test the effect of the factor “degree of compaction”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same amount of soil, the same water, the same container.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
