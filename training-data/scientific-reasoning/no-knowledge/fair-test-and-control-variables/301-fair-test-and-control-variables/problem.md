# 301 — Fair test and control variables

Problem world. Our model mixture contains iron filings, pebbles, sand, and salt dissolved in water. A magnet attracts the iron filings; a sieve separates larger particles from smaller ones; filtration can retain sand while water passes through; evaporating the water can leave the salt behind. A method must be chosen according to the property that differs between the components.

Case data. We want to test the effect of the factor “sieve mesh size”. The group A receives level 1, the group B level 4. For a fair test, the following must be kept constant: the same mixture, the same quantity, the same time of sieving.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
