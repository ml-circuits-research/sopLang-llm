# 316 — Fair test and control variables

Problem world. In the model, light travels in straight lines from a source. An opaque object blocks light and can produce a shadow on a screen behind it. A transparent material lets much light pass through; a translucent material lets only some through. Shadow size can depend on the relative positions of the source, object, and screen.

Case data. We want to test the effect of the factor “distance of the object relative to source”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same source, the same object, the same screen.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
