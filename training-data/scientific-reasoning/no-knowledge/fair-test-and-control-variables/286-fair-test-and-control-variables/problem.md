# 286 — Fair test and control variables

Problem world. In our model, a sensory receptor detects a stimulus, sends a nerve signal, the control center interprets the information, and muscles can produce a response. If the signal does not reach the control center, a response based on that signal cannot be chosen correctly. A fast response is not automatically a correct response; the information must first be detected and transmitted.

Case data. We want to test the effect of the factor “intensity of the stimulus”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same receptor, the same path of signal, the same time.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
