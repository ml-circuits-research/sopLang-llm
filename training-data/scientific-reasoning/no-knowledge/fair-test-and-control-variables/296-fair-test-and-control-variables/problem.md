# 296 — Fair test and control variables

Problem world. Choosing a material depends on the properties required by the object, such as waterproofness, flexibility, transparency, or thermal insulation. No material is “the best” in every situation; it is suitable if it meets the requirements of its use at the same time. In this problem, the properties are stated explicitly and do not need to be guessed from everyday experience.

Case data. We want to test the effect of the factor “thickness the layer insulator”. The group A receives level 1, the group B level 3. For a fair test, the following must be kept constant: the same temperature initial, the same container, the same time.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
