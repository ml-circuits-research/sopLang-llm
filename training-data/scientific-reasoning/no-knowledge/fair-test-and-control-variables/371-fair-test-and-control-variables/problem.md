# 371 — Fair test and control variables

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. We want to test the effect of the factor “number of repetitions”. The group A receives level 1, the group B level 5. For a fair test, the following must be kept constant: the same object, the same instrument, the same procedure.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
