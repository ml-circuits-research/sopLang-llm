# 271 — Fair test and control variables

Problem world. For insect L in this problem, the life cycle has four stages in order: egg, larva, pupa, adult. Only the adult lays eggs, and a larva cannot become an adult without passing through the pupal stage. A temperature in the suitable range may change the rate of development, but it does not change the order of the stages.

Case data. We want to test the effect of the factor “temperature in the interval certain”. The group A receives level 15, the group B level 28. For a fair test, the following must be kept constant: the same number initial of eggs, the same food, the same species.

Question. Design the correct test and explain why changing another condition at the same time would make the conclusion ambiguous.
