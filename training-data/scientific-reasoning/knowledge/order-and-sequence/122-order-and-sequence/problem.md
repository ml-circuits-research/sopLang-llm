# 122 — Order and sequence

Problem world. A measurement is useful only if we know what quantity was measured and in which unit. For comparisons, values must be expressed in the same unit and obtained by the same method. Repeating a measurement can show whether an unusual result is stable or only an accidental error. No conversions need to be memorized in this problem; every required conversion is stated explicitly.

Case data. The stages were written in mixed order: we choose the instrument and unit / we define what we measure / we measure several times / we compare values. The model rule is that each stage in the knowledge sheet must prepare the next stage.

Question. Put the stages in logical order. For each transition, explain why the next stage cannot be placed before the previous one.
