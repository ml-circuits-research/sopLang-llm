# Explanation 82 — Order and sequence

## Explanation

1. The world of the case describes one process, and its stages the object moves toward the magnet, we bring closer the magnet, attraction occurs, the object enters the action zone are the steps of that process written in mixed order.
2. Matching those steps against the knowledge sheet of the process gives the sequence we bring closer the magnet → the object enters the action zone → attraction occurs → the object moves toward the magnet, because each step of the sheet is the one that prepares the next.
3. The first step is the one that depends on none of the others, and every later step uses the result of the step before it.
4. Reversing any neighbouring pair would ask for the effect before the cause, so the order of the sheet is the only order the process allows.

Reference solution as printed in the source (form 2, 4 steps):

1. We look for the stage that does not depend on any of the others in the list: “we bring closer the magnet”.
2. It can be followed by “the object enters the action zone”, because it uses the result of the first stage.
3. The third is “attraction occurs”, and the last is “the object moves toward the magnet”; if we reverse the last two, we would be asking for the effect before the cause or the final state before the intermediate state.
4. We verify the order from beginning to end: each step has the required data produced by the preceding step.

## Result

**Answer.** We bring closer the magnet → the object enters the action zone → attraction occurs → the object moves toward the magnet.
