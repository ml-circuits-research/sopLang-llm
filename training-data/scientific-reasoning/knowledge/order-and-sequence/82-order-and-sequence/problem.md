# 82 — Order and sequence

Problem world. In the model, a magnet can attract certain magnetic materials without direct contact. Two magnet ends can attract or repel depending on orientation. We do not assume that all metals are magnetic; the result of the test is stated explicitly for every object. A thin nonmagnetic barrier does not necessarily stop the magnet’s effect in our model.

Case data. The stages were written in mixed order: the object moves toward the magnet / we bring closer the magnet / attraction occurs / the object enters the action zone. The model rule is that each stage in the knowledge sheet must prepare the next stage.

Question. Put the stages in logical order. For each transition, explain why the next stage cannot be placed before the previous one.
