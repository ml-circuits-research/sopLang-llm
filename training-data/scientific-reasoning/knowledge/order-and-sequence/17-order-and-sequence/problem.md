# 17 — Order and sequence

Problem world. In this problem, a habitat provides resources such as water, food, shelter, and a tolerable temperature. An adaptation is a characteristic that helps an organism in a particular environment; the same characteristic is not equally useful in every environment. For animal Z in the model, good survival requires water, food, and shelter at the same time.

Case data. The stages were written in mixed order: the animal finds shelter / avoids the hours very hot / finds water / goes out to look for food. The model rule is that each stage in the knowledge sheet must prepare the next stage.

Question. Put the stages in logical order. For each transition, explain why the next stage cannot be placed before the previous one.
