# 37 — Order and sequence

Problem world. In our model, a sensory receptor detects a stimulus, sends a nerve signal, the control center interprets the information, and muscles can produce a response. If the signal does not reach the control center, a response based on that signal cannot be chosen correctly. A fast response is not automatically a correct response; the information must first be detected and transmitted.

Case data. The stages were written in mixed order: the muscle performs the response / the signal is interpreted / the signal starts / the receptor detects the stimulus. The model rule is that each stage in the knowledge sheet must prepare the next stage.

Question. Put the stages in logical order. For each transition, explain why the next stage cannot be placed before the previous one.
