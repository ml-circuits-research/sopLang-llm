# 47 — Order and sequence

Problem world. Choosing a material depends on the properties required by the object, such as waterproofness, flexibility, transparency, or thermal insulation. No material is “the best” in every situation; it is suitable if it meets the requirements of its use at the same time. In this problem, the properties are stated explicitly and do not need to be guessed from everyday experience.

Case data. The stages were written in mixed order: we choose the material which meets all the requirements / we eliminate the materials unsuitable / we test the properties / we establish the requirements. The model rule is that each stage in the knowledge sheet must prepare the next stage.

Question. Put the stages in logical order. For each transition, explain why the next stage cannot be placed before the previous one.
