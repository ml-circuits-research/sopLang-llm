# Explanation 846 — The if in Saturday — variant 6

## Explanation

1. Ben's sentence carries a condition: coming on Saturday is promised only if it does not rain.
2. Saturday it rains, so the condition is false and the promise has no scope to be kept or broken; the duty it would create never starts.
3. Cara repeats the promise as if it were unconditional, which drops the “if” from the sentence.
4. The correct reading keeps the condition attached, so the accusation of a broken promise fails.

Reference material as printed in the source:

“I come if P”. ¬P. So “I come” is not owed. “If” is not ornament, even in a quarrel.

## Result

**Answer.** No. The condition is false, so the duty does not start. Cara read without the “if”.
