# 965 — Funding a shared public project: case 5

Knowledge context. Public goods can benefit many people at once, which creates coordination problems about contributions.

Given facts. A community project is built only if total voluntary contributions reach 16 tokens. Contributions from 8 households are [1, 2, 3, 4, 1, 2, 3, 4]. Everyone can use the project if it is built, including households that contribute zero. Cross-domain check: a survey team starts work at 12:00 and works for 2 hour(s) without a break.

Rules. Add contributions and compare with the threshold. A public-good threshold concerns whether the project is produced; it does not by itself decide whether every contribution pattern is fair. For the cross-domain check, finishing time = starting time + duration.

Task. Is the project built? How many additional tokens, if any, are needed? Cross-domain check: at what time does the team finish?
