# 799 — Nested places: Zephyr, Highridge, and Republic C

Knowledge context. Geography uses nested categories: a locality can be inside a region, a region inside a state, and a state inside a continent.

Given facts. Zephyr is in Highridge. Highridge is in Republic C. Republic C is in the continent of Meridian. Another city, Yarrow, is also in Republic C, but its region is not specified.

Rules. If X is contained in Y and Y is contained in Z, then X is contained in Z. The reverse inference is not valid: knowing that two places are in one country does not prove that they are in the same region.

Task. Which larger units contain Zephyr?
