# 618 — Choosing a public budget package: case 3

Knowledge context. Public budgets require choices under limited resources. A transparent model separates costs, benefits, and mandatory obligations.

Given facts. A town has a budget of 18 units. Projects (cost, benefit): park=(4,5); bridge repair=(6,9); library books=(3,4); drainage=(5,8). Cross-domain check: a local committee has 14 members, requires at least 8 present for quorum, and 14 are present.

Rules. Choose a subset whose total cost does not exceed the budget. Maximize total benefit. If a mandatory project is stated, every feasible plan must include it. For the cross-domain check, quorum exists when present members ≥ the stated threshold.

Task. Which set of projects gives the greatest total benefit while satisfying every constraint? Cross-domain check: is quorum met?
