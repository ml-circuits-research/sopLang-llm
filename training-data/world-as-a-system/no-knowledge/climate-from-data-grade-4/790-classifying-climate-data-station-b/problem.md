# 790 — Classifying climate data: Station B

Knowledge context. Climate descriptions summarize long-term patterns. In a reasoning problem, explicit thresholds let us classify numerical data without hidden knowledge.

Given facts. Use this classroom classification: cool if mean temperature <12°C; mild if 12–17°C; warm if >17°C. Dry if annual precipitation <500 mm; wet if ≥500 mm. Data: Station A: T=12°C, P=520 mm; Station B: T=20°C, P=780 mm; Station C: T=16°C, P=560 mm.

Rules. Apply only the stated thresholds. Temperature and precipitation are separate dimensions, so each station receives two labels.

Task. Classify Station B. Then identify whether any other station has the same two-label class.
