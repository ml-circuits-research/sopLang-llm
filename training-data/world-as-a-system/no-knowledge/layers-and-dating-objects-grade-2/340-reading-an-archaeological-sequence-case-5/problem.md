# 340 — Reading an archaeological sequence: case 5

Knowledge context. Archaeological layers provide relative chronological information. Dates from objects add constraints but do not automatically make every date exact.

Given facts. An undisturbed archaeological site has four layers from top to bottom: A, B, C, D. In an undisturbed sequence, lower layers were deposited earlier. D contains an object dated 1320, C contains one dated 1510, and B contains one dated 1680. Cross-domain check: on a field sketch, 1 cm represents 2 km and two checkpoints are 6 cm apart.

Rules. In an undisturbed sequence, a lower layer is older than a layer above it. A securely dated object provides a constraint on the layer that contains it, but one object does not date every other object exactly. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Which is older, Layer C or Layer B? Can the exact year of deposition of Layer A be deduced? Cross-domain check: what real distance separates the checkpoints?
