# 337 — Reading an archaeological sequence: case 2

Knowledge context. Archaeological layers provide relative chronological information. Dates from objects add constraints but do not automatically make every date exact.

Given facts. An undisturbed archaeological site has four layers from top to bottom: A, B, C, D. In an undisturbed sequence, lower layers were deposited earlier. D contains an object dated 1305, C contains one dated 1465, and B contains one dated 1620. Cross-domain check: a survey team starts work at 8:00 and works for 2 hour(s) without a break.

Rules. In an undisturbed sequence, a lower layer is older than a layer above it. A securely dated object provides a constraint on the layer that contains it, but one object does not date every other object exactly. For the cross-domain check, finishing time = starting time + duration.

Task. Which is older, Layer C or Layer B? Can the exact year of deposition of Layer A be deduced? Cross-domain check: at what time does the team finish?
