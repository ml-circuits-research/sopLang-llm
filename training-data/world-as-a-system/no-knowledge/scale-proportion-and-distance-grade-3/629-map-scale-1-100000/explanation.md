# Explanation 629 — Map scale 1:100000

## Explanation

1. The scale 1:100000 means that one centimetre on the map represents 100000 centimetres in reality.
2. Multiplying the measured 8 cm by 100000 gives 800000 real centimetres.
3. Dividing 800000 cm by 100,000 cm per kilometre gives 8 km, and a scale is a ratio rather than an added distance.

Reference solution as printed in the source (family N1, 2 steps):

1. Real centimetres=8×100000=800000.
2. Convert to kilometres: 800000÷100,000=8.
