# Explanation 626 — Map scale 1:10000

## Explanation

1. The scale 1:10000 means that one centimetre on the map represents 10000 centimetres in reality.
2. Multiplying the measured 5 cm by 10000 gives 50000 real centimetres.
3. Dividing 50000 cm by 100,000 cm per kilometre gives 0.5 km, and a scale is a ratio rather than an added distance.

Reference solution as printed in the source (family N1, 2 steps):

1. Real centimetres=5×10000=50000.
2. Convert to kilometres: 50000÷100,000=0.5.
