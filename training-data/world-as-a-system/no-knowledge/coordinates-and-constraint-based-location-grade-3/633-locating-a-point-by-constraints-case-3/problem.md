# 633 — Locating a point by constraints: case 3

Knowledge context. Coordinates turn location into numbers. Multiple spatial clues can be treated as simultaneous constraints.

Given facts. A point P lies on an integer grid with x,y from 0 to 7. It satisfies x+y=12 and x−y=-2. It also satisfies x≥4.

Rules. A location is valid only if it satisfies every stated equation and inequality at the same time.

Task. Which coordinate(s) can P occupy? Is the solution unique?
