# 215 — Funding a shared public project: case 5

Knowledge context. Public goods can benefit many people at once, which creates coordination problems about contributions.

Given facts. A community project is built only if total voluntary contributions reach 10 tokens. Contributions from 5 households are [1, 2, 3, 4, 1]. Everyone can use the project if it is built, including households that contribute zero. Cross-domain check: researchers collected 11 reports, but 4 are exact duplicate copies that add no new independent information.

Rules. Add contributions and compare with the threshold. A public-good threshold concerns whether the project is produced; it does not by itself decide whether every contribution pattern is fair. For the cross-domain check, independent reports = total reports − duplicate copies.

Task. Is the project built? How many additional tokens, if any, are needed? Cross-domain check: how many non-duplicate reports remain?
