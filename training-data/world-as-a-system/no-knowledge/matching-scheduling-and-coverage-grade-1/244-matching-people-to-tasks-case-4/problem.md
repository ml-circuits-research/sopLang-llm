# 244 — Matching people to tasks: case 4

Knowledge context. Scheduling and assignment problems connect people, tasks, times, and constraints.

Given facts. Four students must each receive one different task. Allowed assignments: Ava: ['Map']; Ben: ['Budget', 'Survey']; Cara: ['Map', 'Survey']; Dion: ['Budget', 'Timeline'].

Rules. Each student gets exactly one allowed task, and each task is used exactly once. A complete assignment must satisfy both conditions.

Task. Find one complete valid assignment. If none exists, explain why.
