# 713 — Funding a shared public project: case 3

Knowledge context. Public goods can benefit many people at once, which creates coordination problems about contributions.

Given facts. A community project is built only if total voluntary contributions reach 14 tokens. Contributions from 7 households are [3, 4, 1, 2, 3, 4, 1]. Everyone can use the project if it is built, including households that contribute zero.

Rules. Add contributions and compare with the threshold. A public-good threshold concerns whether the project is produced; it does not by itself decide whether every contribution pattern is fair.

Task. Is the project built? How many additional tokens, if any, are needed?
