# 126 — Map scale 1:10000

Knowledge context. Map scale links a model to the real world through proportional reasoning.

Given facts. A map has scale 1:10000. The measured map distance between two points is 3 cm. Rule: 1 cm on the map represents 10000 cm in reality; 100,000 cm = 1 km.

Rules. Multiply map length by the scale denominator, then convert units. A scale is a ratio, not an added distance.

Task. What is the real straight-line distance in kilometres?
