# 815 — What can one letter prove?

Knowledge context. Historical sources are evidence, not automatic answers. The strength of a conclusion depends on what the source actually records.

Given facts. A historian has one source: a letter. The source directly shows that a named person wrote a message. A student proposes two claims: C1: a named person wrote a message; C2: the whole population agreed with the ruler. Cross-domain check: researchers collected 11 reports, but 4 are exact duplicate copies that add no new independent information.

Rules. A source supports only claims that can reasonably be inferred from what it contains. Absence of evidence for a broad claim is not proof of that claim. For the cross-domain check, independent reports = total reports − duplicate copies.

Task. Which claim is directly supported, and which is not justified by this source alone? Cross-domain check: how many non-duplicate reports remain?
