# 872 — Pairwise collective choice: Library versus Sports Hall

Knowledge context. Group preferences can be aggregated in different ways. Pairwise majority asks a specific question about two options at a time.

Given facts. Three public projects are considered: Park, Library, Sports Hall. Voter groups and rankings: 5 voters rank Park>Library>Sports Hall; 7 voters rank Library>Sports Hall>Park; 3 voters rank Sports Hall>Park>Library. Use pairwise majority: compare two options at a time; each voter supports the one ranked higher.

Rules. For a pairwise contest, count how many voters prefer each of the two options. Ignore the third option for that comparison.

Task. In a pairwise vote between Library and Sports Hall, which option wins?
