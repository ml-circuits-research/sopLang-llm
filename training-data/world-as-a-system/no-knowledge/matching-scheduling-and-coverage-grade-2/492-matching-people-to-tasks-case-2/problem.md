# 492 — Matching people to tasks: case 2

Knowledge context. Scheduling and assignment problems connect people, tasks, times, and constraints.

Given facts. Four students must each receive one different task. Allowed assignments: Ava: ['Map', 'Timeline']; Ben: ['Budget', 'Survey']; Cara: ['Survey']; Dion: ['Budget', 'Timeline']. Cross-domain check: on a field sketch, 1 cm represents 4 km and two checkpoints are 4 cm apart.

Rules. Each student gets exactly one allowed task, and each task is used exactly once. A complete assignment must satisfy both conditions. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Find one complete valid assignment. If none exists, explain why. Cross-domain check: what real distance separates the checkpoints?
