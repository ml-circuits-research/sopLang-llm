# 118 — Choosing a public budget package: case 3

Knowledge context. Public budgets require choices under limited resources. A transparent model separates costs, benefits, and mandatory obligations.

Given facts. A town has a budget of 14 units. Projects (cost, benefit): park=(4,5); bridge repair=(6,9); library books=(3,4); drainage=(5,8).

Rules. Choose a subset whose total cost does not exceed the budget. Maximize total benefit. If a mandatory project is stated, every feasible plan must include it.

Task. Which set of projects gives the greatest total benefit while satisfying every constraint?
