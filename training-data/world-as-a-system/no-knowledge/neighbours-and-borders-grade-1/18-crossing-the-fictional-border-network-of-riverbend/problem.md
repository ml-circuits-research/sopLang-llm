# 18 — Crossing the fictional border network of Riverbend

Knowledge context. Political maps can be treated as adjacency networks. This lets us reason about border crossings without relying on memorized real-world geography.

Given facts. Countries are represented by the fictional states Riverbend, Kite, Fern, Oak, Cedar, Northfield. Shared borders: Riverbend–Kite, Kite–Fern, Fern–Oak, Riverbend–Cedar, Cedar–Northfield, Northfield–Oak.

Rules. Crossing one border corresponds to traversing one graph edge. A route may use only listed borders. A state is unavoidable only if every feasible route passes through it.

Task. What is the fewest number of border crossings needed to travel from Riverbend to Oak? Is Kite necessarily crossed?
