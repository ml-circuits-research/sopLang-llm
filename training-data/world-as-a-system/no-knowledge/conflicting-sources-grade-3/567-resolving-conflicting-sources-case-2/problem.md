# 567 — Resolving conflicting sources: case 2

Knowledge context. Historical accounts can disagree. Reasoning requires evaluating how a source knows what it claims, not simply counting statements.

Given facts. Source A, an eyewitness diary, says the bridge opened on Monday. Source B, a later textbook, says Tuesday. Source C, an independent dated toll record, begins charging on Monday. Cross-domain check: researchers collected 13 reports, but 4 are exact duplicate copies that add no new independent information.

Rules. When sources conflict, compare proximity to the event, independence, and whether a source has a reason or mechanism to record the specific fact. Agreement between independent relevant sources increases support but does not create absolute certainty. For the cross-domain check, independent reports = total reports − duplicate copies.

Task. Which account is better supported by the evidence given, and why? Cross-domain check: how many non-duplicate reports remain?
