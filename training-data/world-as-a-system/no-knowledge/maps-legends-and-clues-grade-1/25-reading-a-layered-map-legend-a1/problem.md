# 25 — Reading a layered map legend (A1)

Knowledge context. A map legend translates symbols into properties. One location may have several properties at the same time.

Given facts. Legend: tree=forest, wavy line=river, double line=road, arch=bridge, square=village, triangle=hill. Cells: A1 has forest, road; A2 has bridge, river; B1 has bridge, forest, river, road; B2 has road, village.

Rules. A cell satisfies the task only if it has every required attribute. Extra attributes do not disqualify it unless the task says so.

Task. Which cell or cells satisfy all of these conditions: river, road? Explain by intersecting the clues.
