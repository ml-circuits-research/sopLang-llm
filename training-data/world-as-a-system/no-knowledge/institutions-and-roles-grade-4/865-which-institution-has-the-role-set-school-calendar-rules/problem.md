# 865 — Which institution has the role? Set school calendar rules

Knowledge context. Civic institutions divide responsibilities. A problem can be solved by matching an action to a clearly defined function.

Given facts. Roles are defined as follows: Town Council makes local policy and approves the budget; Public Works Office maintains roads; Local Court decides legal disputes; Election Committee administers elections; School Board sets school policies. A resident asks which institution should set school calendar rules. Cross-domain check: a survey team starts work at 8:00 and works for 2 hour(s) without a break.

Rules. Match the requested action to the stated role. Do not choose an institution merely because it is powerful or familiar. For the cross-domain check, finishing time = starting time + duration.

Task. Should the request go first to the School Board or the Town Council? Why? Cross-domain check: at what time does the team finish?
