# 940 — Temporal compatibility in a story set in 1500

Knowledge context. Anachronism can be tested as a compatibility problem when the relevant date ranges are supplied.

Given facts. For this problem, availability intervals are: Technology A: 1200–1600; Institution B: 1500–1900; Tool C: 1700–2000; Practice D: 1300–1450. A story is set in 1500 and mentions Technology A and Tool C together. Cross-domain check: on a field sketch, 1 cm represents 2 km and two checkpoints are 4 cm apart.

Rules. An item is temporally compatible with a year only if the year lies inside its stated availability interval. An anachronism is an item placed outside its given interval. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Which mentioned item, if any, is anachronistic in the story? Cross-domain check: what real distance separates the checkpoints?
