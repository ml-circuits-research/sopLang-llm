# 368 — Choosing a public budget package: case 3

Knowledge context. Public budgets require choices under limited resources. A transparent model separates costs, benefits, and mandatory obligations.

Given facts. A town has a budget of 16 units. Projects (cost, benefit): park=(4,5); bridge repair=(6,9); library books=(3,4); drainage=(5,8). Cross-domain check: on a field sketch, 1 cm represents 5 km and two checkpoints are 6 cm apart.

Rules. Choose a subset whose total cost does not exceed the budget. Maximize total benefit. If a mandatory project is stated, every feasible plan must include it. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Which set of projects gives the greatest total benefit while satisfying every constraint? Cross-domain check: what real distance separates the checkpoints?
