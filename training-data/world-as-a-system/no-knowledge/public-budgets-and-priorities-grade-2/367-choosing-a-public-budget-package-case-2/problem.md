# 367 — Choosing a public budget package: case 2

Knowledge context. Public budgets require choices under limited resources. A transparent model separates costs, benefits, and mandatory obligations.

Given facts. A town has a budget of 15 units. Projects (cost, benefit): tree planting=(5,7); bridge repair=(6,9); library books=(3,4); drainage=(5,8). Cross-domain check: researchers collected 13 reports, but 4 are exact duplicate copies that add no new independent information.

Rules. Choose a subset whose total cost does not exceed the budget. Maximize total benefit. If a mandatory project is stated, every feasible plan must include it. For the cross-domain check, independent reports = total reports − duplicate copies.

Task. Which set of projects gives the greatest total benefit while satisfying every constraint? Cross-domain check: how many non-duplicate reports remain?
