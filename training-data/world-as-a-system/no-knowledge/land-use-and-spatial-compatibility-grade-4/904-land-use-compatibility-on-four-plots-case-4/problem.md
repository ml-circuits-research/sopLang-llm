# 904 — Land-use compatibility on four plots: case 4

Knowledge context. Land-use planning combines spatial relationships with compatibility rules.

Given facts. Four plots lie in a line A–B–C–D. Assign one different use to each plot: school, factory, park, homes. Constraints: the factory may not be adjacent to the school; the park must be adjacent to the homes. The school must be on an end plot. Cross-domain check: on a field sketch, 1 cm represents 6 km and two checkpoints are 3 cm apart.

Rules. An assignment is valid only if every use is placed exactly once and all adjacency constraints hold. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Give one valid assignment and explain why it satisfies every constraint. Cross-domain check: what real distance separates the checkpoints?

Additional information. This is case 4 of the family. The cases enumerate the valid assignments, ordered by the use placed on the first plot, then on the second plot, and so on, with the uses ordered as the facts list them; case k takes the k-th valid assignment, starting again after the last.
