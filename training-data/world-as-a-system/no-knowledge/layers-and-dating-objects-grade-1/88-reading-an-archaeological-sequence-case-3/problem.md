# 88 — Reading an archaeological sequence: case 3

Knowledge context. Archaeological layers provide relative chronological information. Dates from objects add constraints but do not automatically make every date exact.

Given facts. An undisturbed archaeological site has four layers from top to bottom: A, B, C, D. In an undisturbed sequence, lower layers were deposited earlier. D contains an object dated 1310, C contains one dated 1480, and B contains one dated 1640.

Rules. In an undisturbed sequence, a lower layer is older than a layer above it. A securely dated object provides a constraint on the layer that contains it, but one object does not date every other object exactly.

Task. Which is older, Layer C or Layer B? Can the exact year of deposition of Layer A be deduced?
