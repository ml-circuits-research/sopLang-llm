# 839 — Reading an archaeological sequence: case 4

Knowledge context. Archaeological layers provide relative chronological information. Dates from objects add constraints but do not automatically make every date exact.

Given facts. An undisturbed archaeological site has four layers from top to bottom: A, B, C, D. In an undisturbed sequence, lower layers were deposited earlier. D contains an object dated 1315, C contains one dated 1495, and B contains one dated 1660. Cross-domain check: researchers collected 15 reports, but 4 are exact duplicate copies that add no new independent information. Mixed-domain verification: a regional archive has 85 map sheets and receives 10 additional sheets during the exercise.

Rules. In an undisturbed sequence, a lower layer is older than a layer above it. A securely dated object provides a constraint on the layer that contains it, but one object does not date every other object exactly. For the cross-domain check, independent reports = total reports − duplicate copies. For this verification, the final number of sheets equals starting sheets plus received sheets.

Task. Which is older, Layer C or Layer B? Can the exact year of deposition of Layer A be deduced? Cross-domain check: how many non-duplicate reports remain? Mixed-domain verification: how many sheets are available after the delivery?
