# 610 — Representing three districts: case 5

Knowledge context. Representation can be modeled by rules that convert population into seats. Different allocation rules can produce different results, so the rule must be stated.

Given facts. Three districts have populations A=200, B=110, C=120. They must share 13 seats. Use this stated method: compute each exact quota population/total×seats; give each district the whole-number part; assign remaining seats to the largest fractional remainders.

Rules. Use only the stated largest-remainder method. Seat totals must add exactly to the available number.

Task. How many seats does each district receive?
