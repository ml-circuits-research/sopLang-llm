# 772 — Reading a layered map legend (A2)

Knowledge context. A map legend translates symbols into properties. One location may have several properties at the same time.

Given facts. Legend: tree=forest, wavy line=river, double line=road, arch=bridge, square=village, triangle=hill. Cells: A1 has forest, road; A2 has bridge, river, village; B1 has forest, river, road; B2 has road, village. Cross-domain check: on a field sketch, 1 cm represents 4 km and two checkpoints are 4 cm apart.

Rules. A cell satisfies the task only if it has every required attribute. Extra attributes do not disqualify it unless the task says so. For the cross-domain check, real distance = sketch distance × kilometres per centimetre.

Task. Which cell or cells satisfy all of these conditions: bridge, river? Explain by intersecting the clues. Cross-domain check: what real distance separates the checkpoints?
