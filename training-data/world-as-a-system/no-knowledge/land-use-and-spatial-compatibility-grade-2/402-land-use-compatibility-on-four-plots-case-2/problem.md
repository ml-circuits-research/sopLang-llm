# 402 — Land-use compatibility on four plots: case 2

Knowledge context. Land-use planning combines spatial relationships with compatibility rules.

Given facts. Four plots lie in a line A–B–C–D. Assign one different use to each plot: school, factory, park, homes. Constraints: the factory may not be adjacent to the school; the park must be adjacent to the homes. Cross-domain check: a local committee has 14 members, requires at least 8 present for quorum, and 14 are present.

Rules. An assignment is valid only if every use is placed exactly once and all adjacency constraints hold. For the cross-domain check, quorum exists when present members ≥ the stated threshold.

Task. Give one valid assignment and explain why it satisfies every constraint. Cross-domain check: is quorum met?

Additional information. This is case 2 of the family. The cases enumerate the valid assignments, ordered by the use placed on the first plot, then on the second plot, and so on, with the uses ordered as the facts list them; case k takes the k-th valid assignment, starting again after the last.
