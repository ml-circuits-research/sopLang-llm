# 969 — Using a shared renewable resource: case 4

Knowledge context. A common resource can be overused when many individually reasonable withdrawals add up to more than regeneration.

Given facts. A shared fishery has 100 fish at the start of the period and regenerates 13. There are 7 users, each planning to take 6. For this simplified exercise, the stock should not decline below its starting level if use is to be called non-depleting.

Rules. End stock = start + regeneration − total harvest. Total harvest is number of users × harvest per user.

Task. What is the end stock? Is the planned use non-depleting under the stated definition? What equal per-user harvest would exactly match regeneration?
