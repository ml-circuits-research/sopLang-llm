# schedule-deadline-feasibility-14 — Schedule Deadline Feasibility

A project schedules the tasks A(1), B(1), C(9), D(7), E(1), F(2), G(5). A must finish before B, A must finish before C, A must finish before D, A must finish before F, C must finish before F, D must finish before E, D must finish before F, D must finish before G, E must finish before G, F must finish before G. The deadline is 14 minutes. Can every task be finished by the deadline?
