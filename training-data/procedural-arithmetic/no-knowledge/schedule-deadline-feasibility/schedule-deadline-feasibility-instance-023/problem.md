# schedule-deadline-feasibility-23 — Schedule Deadline Feasibility

A project schedules the tasks A(5), B(7), C(2), D(5), E(5), F(3), G(5). A must finish before B, B must finish before C, B must finish before E, C must finish before D, D must finish before F, E must finish before G. The deadline is 26 minutes. Can every task be finished by the deadline?
