# dependency-chain-join-1 — Dependency Chain Join

A project runs five work packages in a chain. A takes 7 minutes. B (3 min) and C (7 min) can start only after A but may then run in parallel. D (5 min) needs both B and C finished. E (10 min) follows D. A final safety buffer of 2 minutes is mandatory, and the completion limit is 28 minutes. What is the earliest safe completion time, and is the plan feasible?
