# dependency-chain-join-34 — Dependency Chain Join

A project runs five work packages in a chain. A takes 7 minutes. B (4 min) and C (4 min) can start only after A but may then run in parallel. D (5 min) needs both B and C finished. E (12 min) follows D. A final safety buffer of 5 minutes is mandatory, and the completion limit is 37 minutes. What is the earliest safe completion time, and is the plan feasible?
