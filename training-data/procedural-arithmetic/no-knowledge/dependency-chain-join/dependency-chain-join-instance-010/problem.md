# dependency-chain-join-10 — Dependency Chain Join

A project runs five work packages in a chain. A takes 3 minutes. B (8 min) and C (8 min) can start only after A but may then run in parallel. D (12 min) needs both B and C finished. E (7 min) follows D. A final safety buffer of 6 minutes is mandatory, and the completion limit is 38 minutes. What is the earliest safe completion time, and is the plan feasible?
