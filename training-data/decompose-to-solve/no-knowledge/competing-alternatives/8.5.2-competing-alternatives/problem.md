# 8.5.2 — Competing Alternatives

Scenario. For moving data through several file formats, 68 records must be handled. Option A has a 16-minute setup, processes 11 records per six-minute cycle, costs 31.00 units fixed plus 2.20 per item. Option B has a 16-minute setup, processes 17 per six-minute cycle, costs 29.00 units fixed plus 1.81 per item. The operation must finish within 62 minutes and cost at most 190.28 units. A brochure also gives background information about the domain, but it does not alter these operational numbers.

Main question. Which option should be selected if feasibility is mandatory and, among feasible options, lower cost is preferred? Best decomposition (3 subproblems).
