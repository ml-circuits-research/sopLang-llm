# 8.1.2 — Competing Alternatives

Scenario. For diagnosing or planning a small computer network, 84 network links must be handled. Option A has a 15-minute setup, processes 16 network links per six-minute cycle, costs 43.00 units fixed plus 1.25 per item. Option B has a 11-minute setup, processes 17 per six-minute cycle, costs 36.00 units fixed plus 2.38 per item. The operation must finish within 55 minutes and cost at most 246.15 units. A brochure also gives background information about the domain, but it does not alter these operational numbers.

Main question. Which option should be selected if feasibility is mandatory and, among feasible options, lower cost is preferred? Best decomposition (3 subproblems).
