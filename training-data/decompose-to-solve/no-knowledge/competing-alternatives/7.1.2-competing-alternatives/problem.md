# 7.1.2 — Competing Alternatives

Scenario. For evaluating several sources about the same claim, 84 sources must be handled. Option A has a 15-minute setup, processes 11 sources per six-minute cycle, costs 42.00 units fixed plus 1.81 per item. Option B has a 9-minute setup, processes 18 per six-minute cycle, costs 58.00 units fixed plus 1.29 per item. The operation must finish within 67 minutes and cost at most 203.99 units. A brochure also gives background information about the domain, but it does not alter these operational numbers.

Main question. Which option should be selected if feasibility is mandatory and, among feasible options, lower cost is preferred? Best decomposition (3 subproblems).
