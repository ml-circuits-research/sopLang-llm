# 2.3.9 — Ten-Part Integrated Decomposition

Scenario. In planning seasonal farm work, a plan starts from 83 local units of field tasks. Convert by 0.75 to standard units, then allow 12% process loss. Each batch handles 24 standard units. Up to 1 batches can run in parallel, each wave taking 5 minutes. Setup takes 13 minutes and a mandatory buffer adds 6 minutes. There are at most 8 batch slots. Cost is 44 fixed plus 1.13 per pre-loss standard unit. The deadline is 50 minutes and the budget is 144.28 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
