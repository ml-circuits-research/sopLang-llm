# 1.7.9 — Ten-Part Integrated Decomposition

Scenario. In following a multi-step administrative procedure, a plan starts from 74 local units of documents. Convert by 0.5 to standard units, then allow 8% process loss. Each batch handles 17 standard units. Up to 3 batches can run in parallel, each wave taking 8 minutes. Setup takes 15 minutes and a mandatory buffer adds 12 minutes. There are at most 5 batch slots. Cost is 62 fixed plus 1.32 per pre-loss standard unit. The deadline is 51 minutes and the budget is 174.93 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
