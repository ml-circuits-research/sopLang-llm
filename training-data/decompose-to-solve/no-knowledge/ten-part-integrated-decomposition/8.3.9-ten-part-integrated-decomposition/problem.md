# 8.3.9 — Ten-Part Integrated Decomposition

A plan starts from 134 local units of data sets. Convert by 1.5 to standard units, then allow 10% process loss. Each batch handles 29 standard units. Up to 3 batches can run in parallel, each wave taking 9 minutes. Setup takes 16 minutes and a mandatory buffer adds 11 minutes. There are at most 11 batch slots. Cost is 41 fixed plus 1.58 per pre-loss standard unit. The deadline is 46 minutes and the budget is 453.88 units.

Question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts?
