# 9.3.9 — Ten-Part Integrated Decomposition

Scenario. In planning a small project, a plan starts from 125 local units of project tasks. Convert by 1.25 to standard units, then allow 12% process loss. Each batch handles 14 standard units. Up to 2 batches can run in parallel, each wave taking 4 minutes. Setup takes 14 minutes and a mandatory buffer adds 10 minutes. There are at most 7 batch slots. Cost is 41 fixed plus 1.99 per pre-loss standard unit. The deadline is 62 minutes and the budget is 415.13 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
