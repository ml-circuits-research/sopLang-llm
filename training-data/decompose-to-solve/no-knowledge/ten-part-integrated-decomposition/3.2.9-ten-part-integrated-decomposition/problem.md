# 3.2.9 — Ten-Part Integrated Decomposition

Scenario. In planning water use and storage, a plan starts from 99 local units of litres of water. Convert by 1 to standard units, then allow 12% process loss. Each batch handles 28 standard units. Up to 3 batches can run in parallel, each wave taking 9 minutes. Setup takes 11 minutes and a mandatory buffer adds 7 minutes. There are at most 8 batch slots. Cost is 82 fixed plus 1.59 per pre-loss standard unit. The deadline is 41 minutes and the budget is 280.54 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
