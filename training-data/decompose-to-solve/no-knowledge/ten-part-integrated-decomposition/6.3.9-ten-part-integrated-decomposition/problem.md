# 6.3.9 — Ten-Part Integrated Decomposition

Scenario. In comparing institutional responsibilities in a generic constitutional system, a plan starts from 83 local units of institutional actions. Convert by 0.5 to standard units, then allow 12% process loss. Each batch handles 17 standard units. Up to 1 batches can run in parallel, each wave taking 8 minutes. Setup takes 8 minutes and a mandatory buffer adds 10 minutes. There are at most 7 batch slots. Cost is 80 fixed plus 1.60 per pre-loss standard unit. The deadline is 47 minutes and the budget is 195.36 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
