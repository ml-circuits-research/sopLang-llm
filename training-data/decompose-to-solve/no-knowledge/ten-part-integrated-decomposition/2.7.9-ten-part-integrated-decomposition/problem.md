# 2.7.9 — Ten-Part Integrated Decomposition

A plan starts from 73 local units of dated records. Convert by 1 to standard units, then allow 8% process loss. Each batch handles 28 standard units. Up to 1 batches can run in parallel, each wave taking 6 minutes. Setup takes 17 minutes and a mandatory buffer adds 5 minutes. There are at most 5 batch slots. Cost is 74 fixed plus 0.87 per pre-loss standard unit. The deadline is 50 minutes and the budget is 203.04 units.

Question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts?
