# 1.3.9 — Ten-Part Integrated Decomposition

Scenario. In preparing food for a group, a plan starts from 90 local units of portions. Convert by 1.25 to standard units, then allow 8% process loss. Each batch handles 17 standard units. Up to 2 batches can run in parallel, each wave taking 8 minutes. Setup takes 8 minutes and a mandatory buffer adds 11 minutes. There are at most 9 batch slots. Cost is 78 fixed plus 1.87 per pre-loss standard unit. The deadline is 56 minutes and the budget is 326.54 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
