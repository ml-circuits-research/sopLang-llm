# 2.6.9 — Ten-Part Integrated Decomposition

Scenario. In preparing a software release, a plan starts from 117 local units of release steps. Convert by 0.75 to standard units, then allow 8% process loss. Each batch handles 29 standard units. Up to 3 batches can run in parallel, each wave taking 6 minutes. Setup takes 15 minutes and a mandatory buffer adds 5 minutes. There are at most 8 batch slots. Cost is 65 fixed plus 1.04 per pre-loss standard unit. The deadline is 37 minutes and the budget is 184.09 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
