# 3.8.9 — Ten-Part Integrated Decomposition

Scenario. In planning a print run, a plan starts from 158 local units of printed copies. Convert by 1 to standard units, then allow 4% process loss. Each batch handles 15 standard units. Up to 3 batches can run in parallel, each wave taking 6 minutes. Setup takes 12 minutes and a mandatory buffer adds 8 minutes. There are at most 12 batch slots. Cost is 63 fixed plus 1.08 per pre-loss standard unit. The deadline is 60 minutes and the budget is 280.44 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
