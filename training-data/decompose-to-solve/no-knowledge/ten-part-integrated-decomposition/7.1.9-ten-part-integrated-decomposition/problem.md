# 7.1.9 — Ten-Part Integrated Decomposition

Scenario. In evaluating several sources about the same claim, a plan starts from 129 local units of sources. Convert by 1.25 to standard units, then allow 8% process loss. Each batch handles 29 standard units. Up to 2 batches can run in parallel, each wave taking 9 minutes. Setup takes 16 minutes and a mandatory buffer adds 8 minutes. There are at most 9 batch slots. Cost is 78 fixed plus 0.91 per pre-loss standard unit. The deadline is 70 minutes and the budget is 212.72 units. The data are deliberately mixed rather than grouped by calculation.

Main question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts? Best decomposition (10 subproblems).
