# 4.6.9 — Ten-Part Integrated Decomposition

A plan starts from 133 local units of organism groups. Convert by 1 to standard units, then allow 8% process loss. Each batch handles 20 standard units. Up to 3 batches can run in parallel, each wave taking 7 minutes. Setup takes 11 minutes and a mandatory buffer adds 9 minutes. There are at most 7 batch slots. Cost is 67 fixed plus 1.84 per pre-loss standard unit. The deadline is 57 minutes and the budget is 392.39 units.

Question. Is the plan feasible, and what intermediate outputs should be computed so that each subproblem uses the fewest necessary facts?
