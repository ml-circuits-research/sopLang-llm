# 7.6.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of study findings to authorize. The rules are written in different places: x must be at least 42; it must not exceed 55; operations require x to be a multiple of 10; and a resource limit of 57 units must still leave a reserve of at least 7.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
