# 9.8.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of issues to authorize. The rules are written in different places: x must be at least 69; it must not exceed 71; operations require x to be a multiple of 7; and a resource limit of 75 units must still leave a reserve of at least 5.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
