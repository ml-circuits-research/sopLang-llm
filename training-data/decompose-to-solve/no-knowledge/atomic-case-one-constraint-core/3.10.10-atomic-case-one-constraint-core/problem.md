# 3.10.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of waste units to authorize. The rules are written in different places: x must be at least 33; it must not exceed 38; operations require x to be a multiple of 5; and a resource limit of 40 units must still leave a reserve of at least 5.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
