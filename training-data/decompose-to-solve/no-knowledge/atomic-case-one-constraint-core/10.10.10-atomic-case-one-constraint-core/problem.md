# 10.10.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of submissions to authorize. The rules are written in different places: x must be at least 69; it must not exceed 77; operations require x to be a multiple of 8; and a resource limit of 74 units must still leave a reserve of at least 2.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
