# 2.7.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of dated records to authorize. The rules are written in different places: x must be at least 26; it must not exceed 30; operations require x to be a multiple of 4; and a resource limit of 35 units must still leave a reserve of at least 7.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
