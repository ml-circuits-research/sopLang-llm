# 5.9.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of hazard observations to authorize. The rules are written in different places: x must be at least 45; it must not exceed 49; operations require x to be a multiple of 4; and a resource limit of 52 units must still leave a reserve of at least 4.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
