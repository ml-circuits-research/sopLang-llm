# 7.2.10 — Atomic Case: One Constraint Core

One integer decision x specifies the number of observations to authorize. The rules are written in different places: x must be at least 29; it must not exceed 33; operations require x to be a multiple of 5; and a resource limit of 36 units must still leave a reserve of at least 6.

Question. Should this be decomposed into four problems, or reformulated as one constraint problem? What is x?
