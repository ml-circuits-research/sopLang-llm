# Explanation 30.12 — Which properties does translation preserve?

## Explanation

1. A translation is a rigid motion: it shifts every point by the same displacement without turning or stretching the figure.
2. That property, taken from the fact wire, means distances such as the segment length are unchanged.
3. The length stays 5, so it cannot change through translation alone.

Reference solution as printed in the source (chapter 30, 4 steps):

1. Both endpoints move in exactly the same way.
2. The distance between the endpoints does not change.
3. The segment's length is that distance.
4. Therefore it remains 5.

## Result

**Answer.** No; the length remains 5.
