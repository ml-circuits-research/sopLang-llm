# 3.20 — Can You Reach the Target Number? 5

Start with 16 tokens, which can be divided exactly into pairs. On each move, you may add exactly 2 tokens. The target is 21. Given rule: if a number is made entirely of pairs and we add one more pair, the new number is still made entirely of pairs. Can you reach exactly 21? Explain without trying a very large number of moves.
