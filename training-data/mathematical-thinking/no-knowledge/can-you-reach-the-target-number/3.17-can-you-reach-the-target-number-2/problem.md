# 3.17 — Can You Reach the Target Number? 2

Start with 10 tokens, which can be divided exactly into pairs. On each move, you may add exactly 2 tokens. The target is 15. Given rule: if a number is made entirely of pairs and we add one more pair, the new number is still made entirely of pairs. Can you reach exactly 15? Explain without trying a very large number of moves.
