# 1.3 — Order in a Line 3

Four children stand in a single line, with no two people in the same position. In this problem, “X is before Y” means that X appears closer to the beginning of the line than Y. The clues are: Radu is before Ioana. Matei is before Radu. Ioana is before Sofia. Determine the complete order, from first to last. No information outside the problem is needed.
