# 1.2 — Order in a Line 2

Four children stand in a single line, with no two people in the same position. In this problem, “X is before Y” means that X appears closer to the beginning of the line than Y. The clues are: Daria is before Luca. Matei is before Radu. Luca is before Matei. Determine the complete order, from first to last. No information outside the problem is needed.
