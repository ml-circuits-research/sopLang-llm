# 1.1 — Order in a Line 1

Four children stand in a single line, with no two people in the same position. In this problem, “X is before Y” means that X appears closer to the beginning of the line than Y. The clues are: Mara is before Daria. Ana is before Mara. Daria is before Luca. Determine the complete order, from first to last. No information outside the problem is needed.
