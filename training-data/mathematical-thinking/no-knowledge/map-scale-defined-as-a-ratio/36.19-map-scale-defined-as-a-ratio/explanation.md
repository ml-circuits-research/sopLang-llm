# Explanation 36.19 — Map scale defined as a ratio

## Explanation

1. The scale states that every 1 cm on the map stands for 5 km in reality.
2. The measured 7 cm repeats that correspondence 7 times, so the real distance is 35 km.

Reference solution as printed in the source (chapter 36, 4 steps):

1. Each centimeter corresponds to 5 km.
2. There are 7 cm.
3. 7×5=35.
4. The scale is a conversion rate.
