# Explanation 30.20 — An unknown inverse transformation

## Explanation

1. The figure was moved 5 units to the right.
2. The inverse of a translation has the same distance and the opposite direction, so it restores the initial position without changing the orientation.
3. The required transformation is to translate 5 units to the left.

Reference solution as printed in the source (chapter 30, 4 steps):

1. To cancel the displacement, we need the same distance in the opposite direction.
2. Right is canceled by left.
3. Move 5 units left.
4. Orientation remains unchanged in both translations.

## Result

**Answer.** Translate 5 units to the left.
