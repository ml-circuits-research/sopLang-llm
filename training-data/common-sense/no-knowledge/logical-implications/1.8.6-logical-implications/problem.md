# 1.8.6 — Logical implications

The model contains exactly these rules: 1. If indicator A is active, B must also be active. 2. If B is active and C is inactive, D must be active. 3. If D is active, E cannot be active. 4. If E is active, A is inactive. In the observed case, A is known to be active and C is known to be inactive. Do not assume any relationship that is not stated.

Question. Which values of B, D, and E follow necessarily? Is Rule 4 needed to derive those values in this case, or is it merely compatible with them? Justify each inference by naming the rule used.
