# 8.2.3 — Successive percentage changes

A central indicator starts at 2400 documents. First, a favorable change increases it by 25% of the value that exists at that time. Second, a disruption reduces the remaining value by 20%. One colleague proposes applying '+25% − 20%' once to the original value; another says each percentage must use its own current base. The team treats a difference greater than 1 documents between the two methods as materially relevant.

Question. What is the correct final value? Is the direct add/subtract percentage method acceptable under the stated criterion? Show both transformations and explain the base used by each percentage.
