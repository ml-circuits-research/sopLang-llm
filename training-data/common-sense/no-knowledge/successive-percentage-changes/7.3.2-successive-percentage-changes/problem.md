# 7.3.2 — Successive percentage changes

A central indicator starts at 900 service units. First, a favorable change increases it by 12% of the value that exists at that time. Second, a disruption reduces the remaining value by 5%. One colleague proposes applying '+12% − 5%' once to the original value; another says each percentage must use its own current base. The team treats a difference greater than 1 service units between the two methods as materially relevant.

Question. What is the correct final value? Is the direct add/subtract percentage method acceptable under the stated criterion? Show both transformations and explain the base used by each percentage.
