# 5.6.5 — Time dependencies

A project has six tasks with durations in whole days: A=4, B=5, C=2, D=6, E=4, F=5. A and B can start on day 0. C and D can start only after A; E can start only after both B and C; F can start only after both D and E. Independent tasks may run in parallel and there are no other delays.

Question. What is the minimum project duration? Give the earliest finish times and identify a dependency chain that determines the final completion time.
