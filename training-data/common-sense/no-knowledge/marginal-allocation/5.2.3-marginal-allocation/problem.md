# 5.2.3 — Marginal allocation

There are 6 identical resource units to allocate among programs A, B, and C. The benefit of each additional unit decreases, and units within each program must be taken in order: A: 16, 14, 12, 10 points for units 1–4; B: 19, 17, 15, 13 points; C: 16, 14, 12, 10 points. Every resource unit has the same cost and benefits add across programs.

Question. How should the 6 units be allocated to maximize total benefit? Use marginal benefit and verify that no later unit in a program is selected without all required earlier units.
