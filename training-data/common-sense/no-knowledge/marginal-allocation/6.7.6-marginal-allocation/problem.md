# 6.7.6 — Marginal allocation

There are 6 identical resource units to allocate among programs A, B, and C. The benefit of each additional unit decreases, and units within each program must be taken in order: A: 14, 12, 10, 8 points for units 1–4; B: 15, 13, 11, 9 points; C: 20, 17, 14, 11 points. Every resource unit has the same cost and benefits add across programs.

Question. How should the 6 units be allocated to maximize total benefit? Use marginal benefit and verify that no later unit in a program is selected without all required earlier units.
