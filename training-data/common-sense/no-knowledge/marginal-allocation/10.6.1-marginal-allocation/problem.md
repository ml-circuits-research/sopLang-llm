# 10.6.1 — Marginal allocation

There are 6 identical resource units to allocate among programs A, B, and C. The benefit of each additional unit decreases, and units within each program must be taken in order: A: 19, 16, 13, 10 points for units 1–4; B: 15, 11, 7, 3 points; C: 13, 10, 7, 4 points. Every resource unit has the same cost and benefits add across programs.

Question. How should the 6 units be allocated to maximize total benefit? Use marginal benefit and verify that no later unit in a program is selected without all required earlier units.
