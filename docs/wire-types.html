Wire types

A circuit is a set of named wires; each wire's command decides how its body is analyzed, validated, and executed. The standard vocabulary holds twelve commands, biased toward orchestration, deterministic delegation, explicit neural calls, and typed state. This page is the live record of every command: what it does, how it works, and how new ones are born.

The twelve commands

The value-producing computation surface is literal plus jsEval; three declarative commands absorb the recurring micro-algorithms; modelCall is the explicit neural effect; input is a binding; and the five container* commands stage typed persistent state.

CommandWhat it doesHow it works
literalProduces a literal scalar, JSON value, or text body.Pure: the body is parsed as the value and published unchanged. No dependencies, no execution.
jsEvalExecutes JavaScript over declared $wire dependencies in an isolated realm.Pure unless it stages effects. The sandbox asserts the input/output contract itself (defined dependencies, non-empty slots record, non-null non-undefined non-empty result) and provides the probe(condition, message) helper. Bounded by a JavaScript deadline, charged cumulatively against the request budget.
graphPathAnswers a reachability or neighbour question over a stated undirected edge list.Pure; bounded deterministic breadth-first search in host code. The body names the edges, the start node, and either a target (yes/no) or a count request (the degree). The command owns the whole-number and yes/no contract; the model never writes a queue or a seen set.
aggregateFilters a source list by a declared predicate and reduces the kept records to one scalar: sum, count, min, max, or average.Pure; owns the non-empty and whole-number contract. The predicate is a tiny declarative form (a threshold comparison or a divisibility test), never a second JavaScript.
fractionReduces a ratio to a reduced fraction or a whole number.Pure; runs the greatest-common-divisor in the command. The body names numerator and denominator, or a source list plus a divisor; the command owns the reduced-fraction contract.
modelCallInvokes the configured neural model for a local semantic judgment or generation step.Explicit non-deterministic neural effect, fully logged: the trace records the definition hash and the dependency value hashes. Instruction text is prose; every invocation is a visible cost center that can be ablated.
inputBinds a value supplied by the wrapper, such as the current problem or a runtime parameter.Immutable for one request or declared snapshot. A binding whose name has no declared wire becomes an implicit input node.
containerDeclares a typed persistent collection with its schema and identity policy.Structural state declaration: the schema and identity policy become trusted runtime state; the wire's value is the container snapshot; a commit invalidates the declaration wire so the next epoch returns the new revision.
containerAddStages one or more new records against a target container.Batched container patch, committed at the epoch barrier together with the other compatible patches; the revision increments once per grouped commit.
containerUpsertStages keyed inserts or replacements under a declared merge policy.Batched container patch against the revision visible at the start of the epoch.
containerRemoveStages deletion or tombstone operations under an explicit identity contract.Batched container patch; history stays auditable.
containerFilterDefines a pure derived view of a source container.The predicate runs over a row; the view keeps the source revision through a filter chain, so provenance stays traceable and every link is invalidated by the base commit.

The jsEval sandbox: the abstractions generated code may use

A jsEval body runs in a private guest realm inside a worker thread: a fresh ECMAScript context per call, holding only ECMAScript intrinsics, so generated code cannot reach process, the module loader, or any host object. Values enter and leave as transfer-profile copies. On top of that isolation, the sandbox injects a small set of composable abstractions — the same idea as the declarative wires, at the helper level:

AbstractionWhat it doesHow it works
probe(condition, message)Asserts a domain invariant inside the body.Provided by the sandbox (jsEval 2.1), never written by the body. A failed probe throws and ends the wire as an execution_error. A body that declares its own helper shadows this binding and still runs.
$wire dependenciesBinds the declared dependencies as function parameters.The analyzer reads $name references outside strings and comments; the values arrive as copies, so a guest mutation never reaches a stored value.
circuit.addWire / redefineWire / invalidateWire / invalidateDownstreamStages graph operations from inside the body.Recorded in the guest realm and replayed onto the real transaction after the call; an uncommitted transaction never publishes.
circuit.getDefinition(name)Reads a definition structurally.Records the read; the wire is invalidated when the definition changes. Returns name, known, command, version, definitionHash, body.
circuit.listDefinitions({prefix})Lists definitions by prefix.Records the list read; returns sorted entries with name, command, version, definitionHash.
circuit.commit({key, result})Commits the staged transaction.Returns result; the wire's output contract then applies.
the jsEval contractThe command owns the generic input/output checks.Version 2: every declared dependency is defined, a compiled slots record is non-empty, and the result is not null, undefined, or the empty string — structured execution_errors otherwise, so no body restates them.
the budgetsBounds every call.JavaScript time (default 2000 ms, charged cumulatively against the request budget) and a transaction operation cap; exhaustion is a structured budget_exceeded outcome. Failures are typed: validation_error (syntax), execution_error (body failure), unsupported_value (non-transferable).

These helpers are candidates for the same abstraction-learning loop as the wires: a recurring body pattern that a sandbox helper or a declarative command can absorb is a measured win, not a stylistic preference.

The bloat indicator. The static checker reports, per plan, the wire count against the hand-written JavaScript mass: ~2.2 wires per plan against ~15.4 jsEval lines (7 lines per wire) on the current suite, with 1,468 plans (13.8%) holding at most three wires but more than 25 jsEval lines — the class the next abstractions must absorb. Run it with node skills/data-quality/scripts/static-check.mjs.

Status (2026-09-25): the container commands joined the teaching pipeline in dataset version 7 — the family validator, the program builder, and the provenance battery now admit and judge container plans, and three minimal families (a store built in stages, a store patched by upsert, a store queried by filter) train the shape. The measurement arm is exp-021.

Why the declarative commands exist

Three commands (graphPath, aggregate, fraction) were introduced after a measured audit of the shipped circuits: they each absorb one recurring multi-line transcription. The result, measured on the same base, recipe, and data: the holdout moved from 379 of 705 (53.8%) to 440 of 705 (62.4%), procedural execution errors collapsed from 63 to 13, and later to 1. A declarative command makes its error class impossible instead of merely rarer — the model names the operation, and the runtime owns the traversal, the reduction, or the gcd.

How new wires are born: the abstraction-learning loop

A new wire is never added on taste. The loop is:

  1. Measure. The deterministic analyzer (skills/wire-discovery/scripts/discover-wires.mjs) clusters every shipped jsEval body by normalized shape and ranks candidates by frequency × lines × error share.
  2. Flag. The static data-quality checker (skills/data-quality/scripts/static-check.mjs) marks the monstrous bodies — too many lines, loops, method chains, variables, or nesting — so attention goes only to the flagged ones, never to the whole dataset.
  3. Propose. A candidate names its contract, the measured pattern it replaces, the line reduction, and the error class it eliminates. Candidates that only prettify are rejected.
  4. Validate. A proposal is adopted only after the family round-trip/oracle tests pass and node training-data/verify.mjs executes every shipped circuit and reproduces its printed answer. Verification runs in every phase; no phase ships code that does not solve the problem.
  5. Measure again. The next arm compares the wire against its jsEval baseline on the same holdout; only a measured win keeps the wire.

This loop is the standing goal alongside the benchmark: validate the hypothesis that we can pass 90% on our holdout, and grow an increasingly powerful wire vocabulary experiment by experiment.

Versioning

Every command carries a version in its manifest; the version flows into the trace as commandVersion and into the cache key. A new command, or a behavior change to an existing one, is a parser/runtime change: the specifications (DS002, DS004, DS008) and this page are updated in the same commit, and the dataset is regenerated. The rules are recorded in AGENTS.md.
