Wire types

modelCall

modelCall invokes the configured neural model for a local semantic judgment or generation step — the explicit, fully logged neural effect.

What it does

Recursive neural reasoning is made explicit: a wire body carries the local instruction and refers to dependency values with $name. Use it for semantic decisions, interpretation, synthesis, or generation that no symbolic command can decide; do not use it for arithmetic, sorting, counting, filtering, or formatting, which belong in jsEval.

How it works

An instruction is prose rather than code, so its dependency analysis reads a $name token wherever it appears and an apostrophe never hides an input. The analyzer reports those references as value dependencies, and the validator requires a non-empty instruction body.

The call is fully logged: the trace records the prompt, the generation, the model revision, the sampling parameters, and the latency together with the definition hash and the dependency value hashes. In replay mode a recorded generation is substituted only when those identities match, and the substitution is recorded with the provenance of the entry it replayed. Every invocation is a visible cost center that can be ablated. The command's effect class is neural and its determinism is not guaranteed (version 1.1.0).

Body syntax

The body is prose with $name value references:

@judgment modelCall
Are $left and $right semantically equivalent? Answer yes or no.

Worked example

A circuit that asks the model whether two injected claims agree:

@claimA input

@claimB input

@equivalent modelCall
Are $claimA and $claimB semantically equivalent? Answer yes or no.

The analyzer reads $claimA and $claimB as dependencies, and the trace records the model revision, the generation, and the hashes of the two claim values, so the judgment can be replayed or audited.
