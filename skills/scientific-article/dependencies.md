# Dependencies

The DOCX builder and its ZIP, XML, and Markdown utilities use Node.js built-ins only. Node.js 20 or later is required; check with `node --version`. Node.js is distributed under the MIT license with third-party notices, maintained at https://github.com/nodejs/node and https://nodejs.org/. No npm installation or network access is required for building documents. Missing or older Node.js must be corrected by the operator before running the builder.

Optional render validation uses an existing LibreOffice installation. The environment used to validate the first version contained LibreOffice 24.2.7.2. LibreOffice is licensed under MPL-2.0, with LGPL-3.0-or-later contributions and bundled component notices; source and update information are at https://www.libreoffice.org/ and https://github.com/LibreOffice/core. The tool is not redistributed. Its value is an independent office-layout implementation; ZIP validation alone cannot expose clipping. Check `libreoffice --version` before rendering, use an isolated temporary profile, and never install it during a build. This is an optional external audit tool reused under the user's authorization for local nondestructive document preparation, not a new runtime dependency. Replace it with another already available OOXML renderer when appropriate. Without it, record that visual DOCX validation was not performed.

Optional figure rasterization in this workspace used the existing ImageMagick 6.9.12-98 command, with SVG delegates provided by the host. Source, license, and updates: https://legacy.imagemagick.org/ and https://github.com/ImageMagick/ImageMagick6, ImageMagick License. Check `convert -version`; no executable is redistributed or automatically installed. The core builder accepts supplied PNGs without this tool. SVG originals remain editable. Optional page inspection used existing Poppler `pdftoppm` and `pdftotext`, GPL-2.0-or-later, https://poppler.freedesktop.org/; check each command with `-v`. All optional tools are audit-only and can be omitted when equivalent manual inspection is available.
